## 压力测量

具体数字与机器信息见 [性能测量.json](性能测量.json)。本次基于 i5-12600KF 的 Windows Node.js 单次测量，200 人物、2200 物品、100 并行行动：

- 推进并完成 100 项行动约 45 ms；
- 存档序列化及校验约 41 ms；
- 快照约 1.1 MB。

这些数字说明原型尚未达到技术文档提出的约 4 ms 单批预算；不能视为 150 卡牌场景 60fps 验收。本版正常内容远小于压力场景，后续应引入增量索引、分批预算或 Worker。数字属于一次开发测量，不是跨设备性能承诺。

## 具体实现约定

- 1 tick = 1 游戏分钟；默认 1 现实秒 = 10 tick，3×/6×可选；没有离线补算。
- 数值为原型示例，不是最终平衡。所有职业目前仅实现一级。
- 沈知弦许可两次合奏，720 tick 内结束有效。普通练习可在许可用完后继续。
- 演出合同接受时从茶社账户预留 36 灵钱，履约后转账，过期退回。茶席每日两场；城镇商贸前七日有明确的 24 灵钱日预算来源。
- 药园每轮消耗两份灵草和两枚工钱，产出一份药物；疲劳或缺料时停工。停止委托只阻止后续轮次，已开始的工作可单独取消。
- 调息改善健康；闭关第一次成功带来 30 日身体岁月余裕，后续不重复发放。没有完整寿终/继承系统，也不暗示职业晋升会自动延寿。
- 山道遭遇为单次短流程风险切片；铃击造成固定 3 普通伤害，摄魂成功另增 25 疲劳。尚未实现完整武学与多阶段战斗系统。
- 委托设定与短答复为即时管理操作；实际炼药和角色活动占用主要行动。
- 持久随机键为固定顺序 JSON 数组；种子和语义键 UTF-8 SHA-256，取首 32 位大端值，拒绝 >= 4,294,000,000 的值后取百万分率。
- 已有判定保存概率、抽样和结果，不因道行后来变化、拖拽或读档而重抽。
- 校验和使用键排序后的 JSON，避免字段排列造成误报。校验和用于发现损坏，不作防作弊认证。
- 五份存档在事务成功前不清理旧数据。写锁之外还有数据库头版本检查，保存队列串行合并。
- 普通界面投影不包含未知事实和随机抽样；导出存档保留完整世界用于恢复。
- reference/examples 的草案只做 JSON 与唯一 ID 校验；正式行动使用本工程的严格 schema，未声称完全兼容全部草案操作。

Vite 生产构建及 Edge 流程均通过；此沙箱的 esbuild 开发依赖预打包受祖先目录读取限制。可用随包无依赖静态服务启动已经构建的 dist。

## v0.2 桌面改造

- 原有固定网格、底部配方菜单、右侧行动栏改为整张桌面：研习、交游、创作、谋生、修养、行游六个动词方块。
- 实体卡牌、地点、作品、心得与未回应事件均为桌面对象；拖动空白平移，滚轮以鼠标为中心缩放。自动归位优先保留玩家摆放，并避免卡牌重叠。
- 非模态窗口支持拖动；槽位根据投入对象改变，展示属性提示并高亮匹配卡牌。点击槽位再点击卡牌、双击、Enter 与拖放共享同一组合规则。
- 进行中的人物/工具收进方块，环形计时展示进度，完成后手动收取。收取状态属于 UI，领域奖励仍由原事务结算一次。
- 来信以桌面卡牌和信件入口呈现，选择回应后确认。组织制度和预算仍是辅助管理窗口；未将所有即时管理操作改成卡牌。
- 保存新增可选 ui.tabletop，记录坐标、视角、已收取经历及提示状态。旧存档默认将已结束经历视为已收取，避免升级时旧成果再次占据桌面。准备槽位刷新时释放到桌面。
- 使用自制 SVG 插画、地点标记和 CSS 桌面纹理，未使用《密教模拟器》的图片、音频或文本资源。

设计参照来自 Weather Factory 官方说明：[动作槽位的属性过滤](https://weatherfactory.biz/the-labyrinth-under-the-skin/)、[由卡牌承载选择](https://weatherfactory.biz/the-skeleton-light/)、[动词窗口、成果与缩放](https://weatherfactory.biz/cultist-simulator-the-renewal-of-skin/)。本版采用这些交互原则，保留本项目独立的修真题材和规则。
