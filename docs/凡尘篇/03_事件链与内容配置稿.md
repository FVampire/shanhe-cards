# 凡尘篇｜事件链与内容配置稿

版本：设计提案 v0.1。下列为策划配置，不是可直接导入的运行 JSON；未实现。

## 1. 通用事件契约

事件必须配置：唯一实例 ID、所属链、阶段、触发条件、角色席位、玩家已知信息、选项前置、预计耗时、开始/结束消耗、结果、关系记忆、后续种子、期限、取消/失败/过期结算、人物释放策略、奖励凭据。

相同链在同一角色/目标上不得重复领关键奖励。普通可重复委托每次有独立 ID、有限需求和资金来源。读档重进不重抽人选；满足多个条件只触发一次。

本稿提及“熟悉”“信任”表示关系事实及趋势，不等同当前原型的单一关系数值。重大变更以具体经历为判断依据。

## 2. CH01 初到青溪：食宿与第一份工作

触发：新档抵达；角色 R01/R02 按玩家选择接入。仅触发一次。

阶段：看告示 → 选择食宿办法 → 完成一次低风险劳动 → 结算 → 留下后续渠道。

开场事件：“告示有三张：客舍缺人搬柴，药铺要整理药篓，茶社等人清扫。每张都写着工钱，只有客舍那张还画了一碗饭。”

| 选择 | 成本/结果 | 人物后续 |
|---|---|---|
| 付钱短住，自己择业 | 支付已显示租费，获得独立安排时间 | 客舍经营者仅为普通相识 |
| 包食宿帮工 | 承担明确的工作时段，预留两日食宿 | 完成后可介绍行业，拒绝后续不收回报酬 |
| 先问公开工作 | 短时问询，不消耗介绍费 | 介绍人无后续即释放，工作联系人按需要持久化 |

失败恢复：选了暂不能做的工种，展示缺少条件并允许换工；无钱仍有包食宿办法。借住到期前一日提示续住/搬离，不没收人物或随身物。

终结与释放：租约/工作结清后介绍人可即清；经营者作为岗位身份摘要保留，只有交涉时实例化。成果：住处事实与至少一个工作入口。

## 3. CH02 药篓里的两种叶子：医药入门

触发：药铺帮工或主动求学；角色 R03/R04。前置不要求玩家认识任何人。

阶段：整理药篓 → 发现相似叶片 → 请教或查图 → 处理合格药材 → 协助一次照护 → 获得后续工作。

事件：“两捆叶子形状很像。药铺的人没有催你，只问：‘你凭什么把它们放进同一格？’”

选择：请教（占用老师时间，形成学习记忆）；先查公开图册（更多时间，无关系要求）；承认暂不能判断并交回（无错误用药，减少本次加工收入）。不可把不懂的药直接给病人作为默认晋升捷径。

成果：辨认一种常见药材、合格药包、首次服务记录。普通辨药为医药技能，不自动授予丹师职业。

关系后续：学徒认可谨慎、师傅认可准确；后续可以与学徒交换经验或承接订单，不强制拜师。

期限：已接下的药包按两游戏日交付；未接受前只显示需求日期。到期可退回剩余材料或重新商量交期，不清空已学知识。

释放：药铺师傅、学徒在工作期间 L2，结束回 L1；患者无继续往来则病案保留必要匿名信息。产生照护承诺者保留至康复/转诊/明确终结。

## 4. CH03 雨前的药畦：第一次合作与异常

触发：完成一次药园劳动或接公开照料委托；R04。林小满若合适优先，否则使用随机学徒。

阶段：发现一角萎叶 → 检查水土与虫害 → 安排采收 → 普通原因被处理，但留下规律异常 → 决定是否继续调查。

三种解法：医药判断采收顺序；手艺修排水槽；询问有经验的人并支付合理报酬。每种都能保住部分收成，但留下不同成果与成本。

事件：“雨还没到，那一小片叶子已经贴向同一个方向。小满蹲下看了很久：‘缺水的不是这种样子。’”

结果：解决普通问题给正常报酬；异常位置形成线索，不能因没有感知天赋就永远找不到。后续 MT02 可复测，但不用 MT02 也可交专业者调查。

承诺：如果答应亲自来，实际完成对应劳动才记为兑现；点击“答应”不立即加最终信任。提前告知无法来可协商替代者，失约由具体损失决定后果。

期限：雨前三游戏日，开启事件时才安排有可行余量的天气窗口。过期收成减少，形成后续修复工作，异常线索保留。

释放：按承诺状态保护，结清后学徒回到自身工作摘要；持续合作时进入联系人，不自动成为玩家组织成员。

## 5. CH04 一张旧琴：手艺路线

触发：作坊求工/茶社修理告示；R05，物主可为 R07 或已认识的人。

阶段：检查旧琴 → 听取物主需求 → 决定修法 → 试修 → 演奏检验 → 交付与回访。

选择：保留原木与痕迹（较费时，满足纪念价值）；经同意换料（较低工时，声音改变）；判断超出能力，做基础维护再转交师傅（较低收益但不虚假承诺）。

关键规则：先询问需求，再开始不可逆加工；不能默认最高性能就是物主最满意的结果。材料消耗在开始加工时说明，未用材料归还。

成果：修理技艺、成品记录、报酬；经物主允许可借琴练习，借用不改变所有权。后续奇异木料仅作为可调查线索，不自动变法器。

期限：接受后四游戏日，可协商一次延期；失败产生修复方案与费用上限，不无限扣款。中止必须归还琴与未耗材料。

释放：匠人回岗位摘要，物主在验收/借用未结前保持身份；琴卡永久保留所有者和修理来源。纯验收客人结清后可归档。

## 6. CH05 江上曲未尽：音律路线

触发：茶社工作、公开短演或听雨亭听曲；R07，沈知弦可承担主乐师席位但开局不是熟人。

阶段：听曲相识 → 约一次练习 → 发现缺少的曲段 → 采风/访谈 → 整理作品 → 选择演出或私下合奏。

关系选择：请教技巧、讨论来历、仅欣赏。欣赏不是失败路径，不强制每次交游都取技能奖励。

作品路径：独自整理（较多练习）；与乐友合编（共享署名，协调时间）；保留残曲并写下自己的尾声（明确为改编）。三种都有完整成果，不以战斗加成奖励。

事件：“他说末尾不是忘了。那年船到这里，人还没有等来。你可以补上一段，也可以让这一拍空着。”

演出只在作品可用后签约，明确预留报酬、场地、开始与结束时间；私下完成也计作品成果，赚钱另走短演。

离行处理：乐师行程早于初遇就有来源；展示剩余时间。离开后能依所学独练，有真实关系者留通信地址，可寻另一位乐友。不能因为错过两次合奏就封锁音乐路线。

释放：演出结束结清合同；普通观众即清；共同作者与作品署名保留档案；乐师离境卸载现场而不删除师友关系。

## 7. CH06 县志里的旧水道：学问路线

触发：书院抄录、公开讲会或购买县志；R06 可选，独自也能完成。

阶段：发现年代矛盾 → 查两种记录或访谈亲历者 → 实地观察 → 区分事实与推测 → 成文 → 接受质疑/补订。

选择：急于交稿，标注未证部分（较低报酬但诚实）；补齐证据（更多时间）；与学友合作（分工署名）；放弃结论但整理资料（留下有用资料，不算调查失败）。

成果：《青溪水道考》或《旧水道访谈录》，开启抄书/教学后续。线索指出旧观观测位置，但人物无需通晓修仙。

没有不合理期限；临时讲会有一期截止，错过仍可自己研究。证人离开时保留已获口述与可寻访去向，不要求证人永久留在场景。

释放：匿名受访者可即清，需核对者保存摘要；共同作者保留身份与署名。作品采用永久事实引用，不钉住作者现场实例。

## 8. CH07 老药师的冬病：照护与求道动机

触发：与 R03 合作达到实际经历条件，并出现季节/身体原因；不在所有开局强制发生。不足冬季则使用已存在的旧病复发，不凭标题强改季节。

阶段：发现状态变化 → 普通照护减轻症状 → 阅读允许公开的旧病案 → 得到游方医者线索 → 安排照护与寻访 → 决定后续生活。

选择：亲自留下照护；安排有能力且愿意接手的人再出发；资助寻医并继续本业。每种都需真实时间、人手和费用，不因选择“善良选项”免费同时做所有事。

寻访找到 R10 不等于治愈：对方解释哪些能缓解、哪些尚无办法，可提供调养方法和可靠求道线索。

事件：“他把药方折好，说自己知道这张方子的用处，也知道它到哪里就没有用了。你第一次听见他这样谈自己的身体。”

成果：照护经历、真实关系、修法线索；不以完成支线保证长寿。失败/放弃：药铺另寻帮手、关系根据是否告知变化，基础求道入口始终存在。

释放：照护交接前保护患者和接手者；交接后远方摘要更新病程。没有玩家介入也有可解释的生活结果，不能永久等待或强制死亡。

## 9. CH08 云岫同行：探索与共同经历

触发：玩家带明确目标上山；R08 可由旧相识担任，不能随机强拉正在工作的朋友。

阶段：查路况 → 招人或独行 → 约定费用/采集分配 → 准备 → 风险事件 → 到达/撤回 → 结算。

四种办法：付费护送；互利同行各自采集；充分调查后绕路；延期。若决定硬闯，先显示已知风险，普通伤害与摄魂等特殊效果按原规则分开判定。

途中事件：“前面的脚印只进不出。同行者放下药篓，问你还要不要往上。” 玩家可改变计划，已经消耗的路程与物资不退款，未发生的费用按事前约定处理。

目标可为寻医、调查旧观、采药、寻找木料，复用旅行框架但更换具体专业决策。

退出：到站、返程、中途解散、救援结束均有结算。失散不是直接删除，而是建立待查状态、最后地点及是否需要救援。

释放：结清分账和装备后释放队伍占用；产生重要共同经历者保留摘要。无下一次约定者归回原工作，不永久围着主角转。

## 10. CH09 三扇门：传承来源与选择

触发：获得至少一条可靠异常线索或主动查找公开修法渠道；不要求完成前面全部支线。

宗门：查看招募告示 → 确认组织与办事人权限 → 展示一项真实凡人成果或完成公开基础考察 → 旁听/试学 → 明确杂务与学习责任 → 接受或退出。

散修：获得引荐或实际合作 → 说明求学目标 → 对方展示自己真正会的方法 → 完成合理准备或协助 → 接受有限教学。不能靠无限送礼刷到所有秘传。

独立：取得基础注本 → 核对来源 → 用第二来源或实际观测验证 → 识别缺漏 → 补注/旁听 → 开始适配练习。

事件：“三份回答都没有许诺长生。一份列着门规，一份写着下次相见的地方，还有一份留着你尚未看懂的空白。”

选择只确定当前安排，不永久禁止转向；退出需处理已接受的工作和财物。公开基础方法长期可获取，机构招募错过可下一期参加。

生命周期：招募执事在活动后卸载，申请由组织记录接续；散修按行程离开，教学约定保护摘要；卖书行商结清交易后可离境，方法学习不依赖他常驻。

## 11. CH10 第一缕：初修与现实应用

触发：已验证一种 MT 方法，满足该方法的已知前置。

阶段：解释基本步骤 → 准备环境 → 试行 → 根据具体反馈修正 → 重复出现成果 → 在相关现实事件中应用。

失败分类与出路：理解有误→补注/请教；身体不适→调养/适配练法；环境不对→改时段或地点；过度练习→休息。不得反复显示无信息的“失败，进度归零”。

成功文案样例：“这一次，变化不是碰巧出现。你停下来，它散去；依照刚才的步骤再试，它又缓缓回来。你还不知道这条路有多长，但终于知道第一步踩在哪里。”

应用：MT01 对应受指导的自我调养判断；MT02 复测异常药畦；MT03 复测旧观灵机。旧支线没有出现时生成等价公开应用场景，不强制补做指定主线。

终结：生成方法成果、首次应用事实、篇章回顾。资源奖励一次性，能力为明确新增行动。不自动加寿，不依据总道行赠送其他专业。

释放：指导者有后续师承则保留关系，临时观察者结清后释放；篇章结束不清空镇子或旧友。玩家可留在凡人生活继续玩。

## 12. 24 个短事件种子

短事件均为状态触发，不是每隔固定分钟无条件抽奖。同类有冷却，已经解决的问题不能原样反复发生。表中“即清”仅指无持续约定的临时角色。

| ID | 事件/触发 | 有意义的选择与结果 | 人物收尾 |
|---|---|---|---|
| EV01 | 铺位漏雨/雨天且简陋住处 | 自修、换铺、向店家交涉；改变费用/条件 | 店家回岗位摘要 |
| EV02 | 同住者清早离开/已设行程 | 告别、约通信、安静送行 | 无联系归档，有约定保留 |
| EV03 | 搬柴少一人/公共工作需求 | 接短工或告知替代者；获得报酬 | 无名工友即清 |
| EV04 | 找回零钱/真实多付账目 | 退还或据为己有；账目和信誉后果 | 涉争议者保留至结清 |
| EV05 | 缺一味药/已接受药包订单 | 换合法配方、采购、协商延期 | 订单保护，完成后降级 |
| EV06 | 学徒争论火候/有共同制作 | 对照试做、请教、分批处理 | 记录合作记忆，回 L1 |
| EV07 | 病人付不起全款/已提供服务 | 分期、减免费用、说明可承担范围 | 形成债务才保护摘要 |
| EV08 | 晒药遇雨/材料实际在晒 | 抢收、求助、接受损失 | 新帮手有约定则持久化 |
| EV09 | 琴弦断裂/正常使用或维护期 | 修理、借琴、延期 | 借物者保留到归还 |
| EV10 | 茶客点旧曲/演出需求 | 会则演、不懂则说明、改曲 | 普通观众即清 |
| EV11 | 乐友不同意见/共同作品 | 试两版、讨论署名、分开创作 | 作者历史保留 |
| EV12 | 小童想学琴/公开教学机会 | 与监护人商量教习或婉拒 | 接受才建立教学与监护引用 |
| EV13 | 抄本缺页/真实残本 | 寻异本、标注缺页、退换 | 交易未结前保护卖家 |
