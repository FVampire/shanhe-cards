# 山河问道｜知识、情报与自由探索设计实施计划

版本：v0.2（沿用原文件路径）  
日期：2026-09-21  
状态：三领域探索与个人收藏切片已接入；实施与验证范围见 [知识探索实施记录](知识探索_实施记录.md)。数值和重复游玩体验仍待真人验证。

## 1. 目标与设计依据

让玩家通过打探、传承、观察与试验认识本局的修行规律，再按自己的理解组合材料、器物和功法。获得传承应明显减少弯路，但没有传承的独行者仍能通过探索建立可靠的方法。

重复游玩时，一部分知识永久有效，另一部分答案随新旅程变化，使获取情报持续有意义。玩家长期积累的是基础知识、推理经验和调查方法，不要求每局从零学习，也不能只靠上一局答案解决所有问题。

本机制覆盖炼丹、炼器、功法修炼，后续可以延伸至阵法、符箓与突破。它是共享的知识与探索规则，各领域保留自己的操作、产出和风险。

### 1.1 用户已明确的方向

- 玩家可以打探情报，获取修炼或制作方法的线索，再自由摸索。
- 获得讲解、说明或传承时，有明确的相关提示。
- 随意搭配大部分不生效，少量产生偏差效果，极少量可能出现走火入魔等负面作用。
- 有传承与没有传承存在实际差异，但独狼路线不被完全封死。
- 有些搭配是固定配方，可以跨局保留并直接使用。
- 有些搭配或结果分布只对本局有效，新局需要重新获得情报或验证。
- 上述规则适用于炼器、功法等领域，不仅限于丹药。
- 玩家可以自由收藏组合或单件物品、自定义名称，用于整理、查看与归类；收藏不限定于已验证方法。

### 1.2 本稿提出的实现方案

分层知识、局内规则稳定、无效组合的反馈方式、风险征兆、情报颗粒度、随机生成约束、内容数量和里程碑均为落实上述方向的设计提案，不视为已确认数值或已实现功能。

## 2. 与现有项目的关系

沿用项目企划 v0.3 的专业分工、有限岁月、独行可行与道行边界。道行仍只直接参与既定的特殊效果抵抗与趋吉避凶；本系统不额外赋予道行配方成功率、研究速度或功法兼容加成。

现有凡尘篇已经包含求道渠道及理解、试行、纠错、复验、应用流程，可作为接入入口。完整自由多卡配方仍属待实现范围。本计划先新增受控试验内容，不把所有现有任务同时改成随机规则。

本稿补充跨局知识与局内探索机制，不据此决定永久死亡、多代继承或完整跨局成长系统。

“一局”在本计划中默认指一次新建旅程。同一旅程的读档、旅行、闭关不重新生成规则。旧存档如何接入见第 10 节。

## 3. 知识分层与跨局保留

| 层级 | 内容 | 新旅程处理 | 用途 |
|---|---|---|---|
| 固定配方 | 已定义的稳定组合与步骤 | 已发现记录保留，可直接按条件使用 | 基础生产、常用操作、降低重复劳动 |
| 通用原理 | 稳定的类别关系与推理原则 | 保留 | 帮助理解新情报和缩小试验范围 |
| 本局规律 | 特定材料契合、功法兼容、产物分布等 | 重新生成，旧记录不作为本局事实 | 保留调查与路线选择的价值 |
| 个人实践 | 本局角色的熟练度、伤势、修炼进度 | 不因图鉴保留而自动继承 | 区分玩家知道与角色实际练成 |

界面明确标识“通用知识”“本局已知”“本局待验证”。上一局的具体结论只作为可选历史记录展示，默认不混入本局有效方法列表。

固定配方跨局可直接使用，指不必重新获取配方；仍需满足其原有材料、工具和操作能力条件，不自动继承上一局的器物与专业熟练度。

不以“拥有情报卡”作为所有行动的权限开关。玩家没有情报，也可以尝试合法的未知组合；若实际条件正确，应按同一规则结算。情报提供确定性与指导。

## 4. 本局规则如何变化

### 4.1 固定框架与局内参数

固定框架定义允许参与的类别、行动方式、可能结果和基本边界；新旅程生成本局参数，例如组合映射、兼容关系、结果权重及必要条件。

示意：玩家得知“A 类与 B 类按某种方法结合，可产生 C 类成果”。这条情报可能只揭示类别，不保证具体 C1、C2 或品质。材料实例还可能具有纯度、具体属性或例外条件，类别推理需要保留适用范围。

若该规则允许稀有异变产物 D1，情报不能同时承诺“必定只产出 C 类”；应区分通常结果和例外。

| 示例结果 | 种子甲 | 种子乙 |
|---|---:|---:|
| C1 | 90% | 50% |
| C2 | 5% | 40% |
| D1：稀有异变 | 0.1% | 0.1% |
| 其他已定义结果或失败 | 4.9% | 9.9% |
| 合计 | 100% | 100% |

以上仅演示用户提出的跨局分布变化，不作为平衡定值。“其他”在正式配置中必须展开为明确结果，不能留下无法结算的概率缺口。

### 4.2 两种可配置的变化方式

- **局内特定关系**：直接从经过设计的候选规则中生成本局映射，例如某两部功法在本局的兼容关系。允许独立存在，不强制每种变化都用地脉解释。
- **共享条件影响**：若干组合受到同一局内条件影响，例如某类材料的灵性倾向。调查一个条件可以推导多个用途，减少逐条查表。

建议两者并用。基础内容以固定规则为主，值得探索的分支加入局内变化；不随机化所有配方，不要求每一条基础操作都重新调查。

### 4.3 生成约束

1. 同一旅程内，相同输入和条件对应同一套规则与概率；单次结果仍可随机。
2. 情报、传承讲解、试验结算共用本局规则，不能分别随机生成互相矛盾的真相。
3. 新局变化应能影响材料选择、修炼路线、成本或风险，避免只有无关紧要的数字变化。
4. 核心成长必须存在可获得的有效路线，且至少一条不要求入宗。
5. 稀有异变不成为主线唯一通行条件，不要求刷极低概率才能推进。
6. 同一局内不因玩家已发现答案而暗改规律。若以后加入世界事件改变条件，须有明确事件、适用范围与记录更新；首版不做动态改写。

## 5. 情报与传承

### 5.1 情报是命题，不只是完整配方

| 情报类型 | 示例 | 提供的帮助 |
|---|---|---|
| 方向 | 某种灵液适合引导这类材料 | 缩小候选范围 |
| 排除 | 此铁不可与赤铜同炼 | 避免一类无效或危险组合 |
| 步骤 | 第三周天须先收气再转脉 | 补齐操作顺序 |
| 条件 | 两法同修需要寒性灵物镇压 | 说明缺失条件 |
| 倾向 | 此法多成 C1，偶得 C2 | 支持收益判断 |
| 风险与补救 | 出现气息逆行时应立即收功 | 提供识别与处理办法 |
| 完整方法 | 材料、步骤、条件、例外和风险说明 | 支持稳定执行 |

传闻、实测记录与完整讲解必须显示来源和适用范围。证据状态可采用“传闻／已获讲解／试验观察／已验证”，不能把一次偶然成功自动标成概率已证实。

可靠的本局传承可以直接揭示规则，不强制玩家把老师讲明白的内容重新刷成“已知”。随机产出一次不符合高概率倾向，也不代表传承错误。

### 5.2 获取途径

打探、请教、交换心得、购买记录、探索残卷、鉴定材料和自行试验均可提供情报。入宗提供成体系的讲解、设施和纠错支持；散修师承与独立研究提供其他路径。

已取得的同一情报原则上归入笔记，不要求为重复使用反复购买。再次付费应对应新增条件、深入解释或针对当前疑难的指导。

### 5.3 传承与独行的差异

| 维度 | 有传承 | 独立摸索 |
|---|---|---|
| 起步 | 有完整或较完整路径 | 从零散线索筛选候选 |
| 成本 | 少走弯路，但可能有贡献、人情或门规义务 | 更多时间与试验材料，自主性高 |
| 风险 | 更早识别征兆并获得补救方法 | 依靠观察、鉴定和小规模试验积累判断 |
| 长期成果 | 深入理解、改良传承 | 补全方法、形成自己的研究记录 |

不对独行身份额外施加隐藏失败倍率。差异来自实际掌握的知识、准备、手艺和支持。

## 6. 自由堆叠与试验反馈

核心流程：取得线索 → 形成假设 → 选择材料或功法 → 提交试验 → 观察结果 → 更新笔记 → 调整并复验 → 实际使用。

“大部分乱搭不生效”适用于无依据的全量组合空间。得到有效线索后，玩家应明显缩小范围，不能仍然面对大量毫无信息的失败。

| 结果 | 行为与成本建议 | 反馈 |
|---|---|---|
| 不构成行动 | 不启动，不消耗 | 说明没有形成可执行操作 |
| 条件不全 | 尚未操作时不消耗；实际试验按预告消耗 | 按已知程度提示缺少条件或观察到的现象 |
| 有效反应但未成 | 消耗时间和试验材料 | 留下残渣、半成品或可解释的观察 |
| 正常成果 | 按领域规则结算 | 记录本次条件与结果 |
| 偏差成果 | 产生有因果的替代效果 | 展示用途、代价及可进一步研究的方向 |
| 危险异常 | 按实际风险条件触发 | 提供征兆、处置与后果记录 |

无效组合不能成为无限免费鉴定器。基础界面只识别操作结构；涉及隐藏性质的结论需要观察或正式试验才能得到。

未知组合允许玩家选择有限的工艺、顺序或运转方式，不引入任意文字解析。界面优先支持相关卡牌和明确操作，避免要求玩家枚举任意数量、任意排列的卡堆。

有讲解时，卡牌匹配界面显示已知步骤、材料范围和风险；未获讲解时，显示当前已知部分和未知项，不偷偷提前揭示答案。桌面整理不自动触发服药、合炼或危险运功，进入操作区并执行后才结算。

## 7. 各领域的具体表现

### 7.1 炼丹

变化对象包括材料契合、产物类型、品质倾向和副作用。玩家可通过辨药、小批试炼、调整辅料和工艺验证情报。

示例：同属 C 类的两种丹药分别偏向恢复与养神；本局分布影响玩家选择生产路线。偏差丹药可以有效但附带燥热，不能只有品质下降一种失败表现。

### 7.2 炼器

变化对象包括材料组合、阵纹兼容、成器属性与缺陷。固定锻造步骤保留，某些合炼和铭刻关系随局变化。

示例：甲局“某类金属＋某类灵晶＋导灵纹”更容易得到稳定导灵器，乙局更倾向蓄灵器；调查材料契合后，玩家决定做日常工具还是储备法器。偏差可能表现为储量高但释放不稳，后续可研究用途或修复。

### 7.3 功法

变化对象包括功法兼容、运行顺序、辅助条件及角色适配。已练成的能力来源仍须追溯到具体学习与实践。

功法不机械照搬炼丹的“随机出货”：优先用本局稳定的兼容与条件关系决定能否协同、修炼效率和可能隐患；在确需不确定性的实践阶段再加入受控随机结果。

示例：甲法与乙法在本局可以衔接，但必须先收气再转换；完整讲解直接提供步骤，残卷只描述现象，独行玩家可用低强度试行逐步确定顺序。新局需要重新确认局内条件，但基础操作知识继续有效。

## 8. 偏差与走火入魔

偏差效果应与材料性质、工艺、功法冲突或环境有可追溯关系。允许玩家把部分偏差开发成特殊用途，不将所有非标准结果都视为废品。

走火入魔等严重负面作用集中在确有危险的操作：强行突破、冲突功法同修、未经验证的高强度运转等。普通物品随意堆放不进入全局低概率灾难抽奖。

首版建议采用以下风险梯度：

1. 无效：不启动或没有修炼收益。
2. 轻微偏差：损耗材料、疲劳、短期不适，可恢复。
3. 危险征兆：提供中断、降强度、加入稳定条件或请教的选择。
4. 严重后果：在明确危险条件与继续操作下发生，提供原因与恢复途径。

风险数值暂不锁定。必须同时考察单次概率、预期尝试次数和后果强度，不能只因概率低就忽略长期累积风险。首版暂不加入无提示的永久废档惩罚。

## 9. 最小原型与实施阶段

### 9.1 最小内容范围建议

- 炼丹、炼器、功法各一条探索链，均包含情报、试验、反馈和实际应用。
- 每个领域至少一个固定方法和两个经过设计的局内变体。
- 三种情报来源：打探、完整讲解、自行试验；都能补全至少一项局内结论。
- 一个可利用的偏差成果，一条带征兆与恢复方式的危险功法试验。
- 一份通用知识图鉴和一份本局研究笔记，记录尝试条件，避免重复劳动。
- 至少两组可对照种子，使相同旧知识在新局需要调整决策。

数量为制作起点。先用受控候选模板生成，不做无边界程序生成，不同时随机化现有全部内容。

### 9.2 里程碑

| 阶段 | 交付内容 | 完成条件 |
|---|---|---|
| P0 规则与内容整理 | 固定／局内知识目录、三领域样例、情报与真实规则对照 | 每条情报有对应事实，每条探索链都有可行终点 |
| P1 局内规则底座 | 种子生成、规则快照、统一结算入口、内容约束检查 | 同局稳定、跨局可变、所有合法种子核心路线可达 |
| P2 情报与知识展示 | 打探和讲解接入、来源与范围标识、图鉴与研究笔记 | 已知提示准确，历史答案不误充本局事实 |
| P3 自由试验 | 未知组合、有限步骤选择、反馈与观察记录 | 无情报也可正确操作，失败能帮助缩小范围 |
| P4 三领域切片 | 丹、器、功法实例，偏差与风险处理 | 三领域共享知识框架，同时保留各自效果与成本 |
| P5 跨局体验与整合 | 连续新旅程试玩、存档接入、数值和反馈调整 | 老玩家仍有调查动机，独行路线可持续，现有流程不回归 |

阶段按依赖顺序推进，不承诺未经评估的日历工期。未验证核心探索反馈前，不扩充大量配方。

## 10. 数据与存档方案

实施约定（2026-09-21）：根据项目 `AGENTS.md`，可发布版本前不要求兼容旧存档。下述旧档兼容建议本轮不执行；当前版本内的规则快照、随机与结算一致性仍须保证。

建议明确区分以下数据职责，字段名在正式接入时遵循现有工程约定：

| 数据 | 保存内容 |
|---|---|
| 固定规则定义 | 类别、输入条件、步骤、结果范围、规则版本 |
| 本局规则快照 | 旅程标识、生成版本、种子、实际映射、概率和兼容条件 |
| 情报定义与实例 | 指向的规则、揭示部分、来源、适用旅程与条件 |
| 知识记录 | 内容、范围、证据状态、来源与验证时间 |
| 试验记录 | 输入实例、操作条件、观察、产物及消耗 |
| 随机与行动状态 | 随机流状态、行动标识、已固定的结算结果和结算状态 |
| 跨局图鉴 | 已发现固定配方与通用原理；与角色成长分开 |

世界生成和单次产出使用分离的随机流，查询情报或打开笔记不改变后续结算。读档不重抽世界规则，同一已开始行动按保存的判定状态继续，避免刷新直接改变既定结果。

不能只保存种子而依赖最新生成算法重建旧局；保存实际规则快照及版本，避免更新后旧情报失效。已有概率型结果、资源占用和结算记录需要防止重复消耗或领取。

旧档接入优先使用兼容模式：保留原有有效方法与剧情，新增系统只覆盖新建试验内容；是否提供主动升级另行制定迁移规则，不静默重抽旧档已知规律。

跨局图鉴的存储与导入导出要与旅程存档明确分开。导入旧旅程不得将其局内结论自动合并为当前旅程事实；新档不得通过保留历史笔记提前标记本局已验证。

## 11. 验收与试玩

### 11.1 规则正确性

- 两个对照种子中，固定配方与通用原理保持有效，指定局内关系或分布确实变化。
- 本局情报、界面提示和实际结算引用相同规则；不同条件的记录不会被错误合并。
- 概率之和完整，结果都有定义；声明的必得产物与稀有异变不存在逻辑冲突。
- 存取档后规则、知识、行动与随机状态保持一致；重复读取不重复发奖。
- 无情报但正确搭配能生效；拥有情报但材料或手艺不足不会绕过实际条件。
- 改变道行不直接改变专业试验与功法兼容结果。
- 内容检查覆盖每个候选模板；种子抽样检查资源与路线可达性，并提供失败种子复现记录。

### 11.2 玩家体验

| 验收问题 | 观察方式 |
|---|---|
| 调查是否有决策价值？ | 情报是否促使玩家改变至少一个材料、步骤、用途或修炼选择 |
| 旧知识是否仍有价值？ | 第二局玩家能复用固定方法，并用通用原理缩小探索范围 |
| 新局是否仍需调查？ | 上局有效的具体答案不能保证解决本局全部探索内容 |
| 自由试验是否可理解？ | 玩家能说明一次失败提供了什么线索，而非只记得材料消失 |
| 传承是否有优势？ | 对照完成同一目标的时间、消耗和误判，玩家能解释差异来源 |
| 独行是否可持续？ | 不入宗、不取得完整传承仍能完成切片目标，并维持基本生活 |
| 风险是否合理？ | 玩家能识别危险征兆并选择停止或处理，后果有可追溯原因 |
| 是否出现重复劳动？ | 记录反复购买同一信息、重试已知无效组合和无选择的固定调查步骤 |

记录完成目标的耗时、试验次数、材料损耗、无新增信息的重复行为及退出探索的原因。具体通过阈值在首轮试玩后设定，不将未测试数字当成已达成指标。

跨局试玩应由同一位玩家连续体验至少两组种子，以区分“第一次觉得新鲜”与“重复游玩仍有判断空间”。

## 12. 暂缓事项与后续决策

暂缓：全配方独立随机、随时改变本局规律、自动生成任意功法、完整谣言欺骗网络、无提示永久损伤、大规模跨代知识继承。

后续通过切片确定：

- 各领域固定内容与局内变化的比例；不预设统一百分比。
- 普通情报展示定性倾向还是精确概率，以及完整讲解的揭示程度。
- 材料关系、环境条件和角色适配分别承担多少变化，避免同一结果受过多隐藏因素影响。
- 试验成本与风险强度，尤其是有限寿数下独行研究的时间负担。
- 固定配方图鉴在多存档、导入导出和版本更新中的合并规则。

实施优先级：先让玩家能从情报和试验中学到可靠的东西，再验证新局变化是否产生新的选择，最后扩充配方、传承和探索内容。

## 13. 借鉴方向：直接操作、熟练生产与实际成果

本项目已经借鉴《密教模拟器》的组合探索、情报、事件与行动结构，不把这些共性重复列为《Stacklands》带来的新增设计。本轮借鉴重点是减少行动入口查找、改善重复生产，以及让制作成果改变后续可执行的操作。

《Stacklands》官方介绍以人物直接堆叠到资源上采集、材料组合建造、Idea 卡解释制作方法为例；这里只将其作为交互参照，下列内容均是本项目的改造提案，不声称为该游戏独有机制。参考：[Stacklands 官方介绍](https://sokpop.itch.io/stacklands)。

### 13.1 明确用途直接堆叠，多义行动再选择

对已有明确用途的采集、加工与研读，允许玩家直接组合对象进入行动。若同一组合可以表达多种合理用途，再提供简短选择。

| 组合示例 | 建议交互 |
|---|---|
| 自己＋可采集资源 | 展示已知耗时与占用后，按普通行动规则开始 |
| 材料＋加工器具 | 单一合法加工方式直接呈现，多种方式再选择 |
| 自己＋功法 | 依据当前状态提供研读、试行或修炼，不盲目推断玩家目的 |
| 自己＋人物＋疑难 | 进入针对该疑难的请教 |
| 收藏的试验组合 | 放入准备区，检查条件，再由玩家执行 |

减少入口不等于取消风险提示。普通桌面重叠、整理与正式操作区要有明确区别；服药、危险运功和不可逆消耗仍遵循原有执行边界。点击与键盘操作继续提供与拖拽等价的入口。

### 13.2 已掌握的生产减少重复操作

把“发现一种方法”和“重复使用这种方法”分开：发现阶段保留试验与判断，熟练阶段提供常用收藏、一键准备及后续有限批量生产。

- 重复执行仍读取当前材料、人物、设施、条件与局内规则，不复用上一次产出结果。
- 连续加工必须有实际执行者和可用设施，不突破人物主要行动占用限制。
- 有限批量生产显示数量、资源预算与预计时间，材料不足、条件变化或危险异常时停止并提示。
- 未知高风险试验不默认加入自动循环。首轮收藏功能不附带批量生产引擎。

### 13.3 成果改变后续行动能力

新增工具、设施与研究成果时，应说明它具体增加了什么办法，而不只增加统一效率数值。

| 成果示例 | 后续变化 |
|---|---|
| 可调火候的炉具 | 支持原先不能执行的控火步骤 |
| 探灵器 | 增加材料观察手段，帮助缩小未知组合范围 |
| 稳定供给与储备 | 支持更长时间的修炼安排，同时仍受实际资源限制 |
| 整理完成的器谱收藏 | 更容易复查步骤与准备材料，不自动增加炼器能力 |

不据此加入强制人口扩张、所有内容随机抽取或碰触敌人立即开战。新增机制必须服务个人修行、独行可行与已有生活系统。

## 14. 自定义收藏：从物品清单到个人手札

### 14.1 基本定义

玩家可以将单张卡、多张卡或当前组合保存为收藏，自由命名、备注和归类。例如将 1、2、3 收藏为 A，将 4、5、6 收藏为 B；这些名称不要求对应系统预设配方。

收藏表示“玩家想把这些内容记在一起”。它可以是有效方法、待验证猜想、备料清单、研究对象或个人纪念，不要求通过配方校验才能保存。

收藏引用对象，不复制实物、不自动移动实物、不占用或消耗实物。同一物品可以出现在多个收藏中。删除收藏只删除整理记录。

| 收藏名称示例 | 内容 | 用途 |
|---|---|---|
| 赤阳剑试作 | 两种材料、阵纹与备注 | 保存未验证的炼器猜想 |
| 闭关准备 | 功法、丹药、食物与数量 | 备料清单，不必构成单个行动 |
| 暂时不知用途 | 多件未知材料 | 整理研究对象 |
| 我的养神法 | 功法、步骤与注意事项 | 保存研究方法和实践经验 |
| 师父遗物 | 指定器物实例 | 定位与纪念 |

### 14.2 保存内容与对象引用

| 内容 | 保存规则 |
|---|---|
| 名称、备注 | 玩家可编辑；名称不是唯一标识，可重名 |
| 条目内容 | 保存所选对象、所需数量及引用方式 |
| 种类引用 | 表示某种材料或物品，便于后续按库存准备 |
| 实例引用 | 表示特定一件物品；售出、损毁或不在当前旅程时显示状态 |
| 操作信息 | 按需保存行动类型、步骤、顺序、器具、火候等玩家已设置的信息 |
| 标签与整理 | 玩家自定义标签、置顶、排序；初版不做多层嵌套 |
| 来源关联 | 可关联情报、试验记录和所属旅程，便于追溯 |

普通可替换材料默认按种类和数量保存；独特器物允许按实例保存，保存时显示引用方式。玩家可以修改选择，系统不擅自将特定实例转换成任意同类替代品。

未知材料只保存玩家可见身份，不因收藏暴露真实属性。类别替代必须由玩家显式选择，不能由系统自动推断未发现的兼容关系。步骤缺失时允许保存为不完整草稿。

### 14.3 查看、定位、准备、执行分开

1. **查看**：列出内容、备注、库存总量、当前可用量与缺少项；实例不可用时说明原因。
2. **定位**：在桌面或库存定位对象；同类候选较多时提供选择，不暗中替玩家判断隐藏优劣。
3. **准备**：将玩家选定且可用的对象放到准备区，不启动行动、不消耗材料；不抢占正在使用或不属于玩家的物品。
4. **执行**：构成行动后，经过统一条件检查和既定风险提示，按正常流程启动。

闭关清单等跨多个行动的收藏只支持查看和准备，不强行转换成一个配方。未知但结构合法的组合允许进入试验，不因“未验证”被拒绝；不构成行动的收藏不会因此触发试验消耗。

一键准备建议只处理当前可取得的库存。缺料时列出缺项并允许玩家准备已有部分，不自动购买、借用、跨地点调运或取消其他任务。

### 14.4 整理与查找

- 从单卡菜单、多选卡牌或当前准备区创建收藏。
- 支持重命名、编辑备注与数量、修改标签、手动排序、置顶和删除。
- 按名称、备注、物品名称与标签搜索，按本局适用性和研究状态筛选。
- 从物品查看引用它的收藏；从收藏定位物品与相关研究记录。
- 名称保持玩家原文，系统状态单独呈现，不用自动改名表达验证结论。
- 收藏界面承担长期整理，桌面仅在需要时显示快捷入口，不为每份收藏永久生成占空间的实体卡。

### 14.5 收藏与验证状态相互独立

玩家即使命名为“必成筑基法”，系统仍独立显示事实，例如“本局未验证”“一次成功记录”“曾发生异常”。同一收藏可以同时存在成功和异常记录，不能用一次结果覆盖全部历史。

只有适用的完整讲解、已知固定规则或明确的验证机制才能支持对应结论。一次偶然成功不证明稳定有效，更不能推导精确概率。

收藏、搜索、缺料计算与准备界面只读取已知信息及物品可用状态，不调用隐藏配方匹配来泄露答案。任何玩家手写结论都保留为个人备注，不自动转成系统事实。

### 14.6 跨局与编辑行为

默认跨局保留收藏名称、内容模板、备注、标签和个人排序。新旅程重算物品可用性与本局证据：

- 固定方法继续有效，实际执行仍需要资源与能力。
- 涉及局内变化的结论显示“本局待验证”，旧局记录保留明确来源。
- 混合收藏逐项标识适用范围，不因为其中有固定配方就把整份收藏判为有效。
- 指向旧局特定实例的条目显示“来自其他旅程／当前不可用”，不自动绑定到同名物品。
- 当前准备区与资源占用不跨局继承。

更改名称或标签不影响验证记录。修改材料、数量、顺序或条件后，原观察保留在原组合版本下，不自动证明新版本有效；可提示“组合已修改，相关结论待重新确认”。

收藏是一份个人手札，不代表角色自动学会其中内容。未来可以讨论整理成传承或传授他人，但本轮不实现收藏直接创造功法、生成配方或增加熟练度。

## 15. 新增实施安排、数据与验收

### 15.1 与原里程碑衔接

| 阶段 | 增补内容 | 验收重点 |
|---|---|---|
| P0 | 列出适合直接堆叠的操作，确定收藏引用与步骤结构 | 简单行动不增加入口，多义与危险行动仍明确 |
| P1 | 收藏稳定标识、对象引用、组合版本与旅程范围 | 与世界规则、角色成长、物品实体分离 |
| P2 | 自由收藏、命名备注、标签搜索、数量和缺料显示、桌面定位 | 未验证组合与单件物品都能保存并找到 |
| P3 | 从准备区保存组合、关联试验记录、一键准备 | 准备不等于执行，旧记录不误用于修改后的组合 |
| P4 | 三领域各加入能改变后续操作的工具或成果样例 | 新成果有实际用途，不只增加数值 |
| P5 | 跨局收藏体验、连续操作成本与存档验证 | 整理积累保留，本局规律仍需确认 |

有限批量生产在手动重复流程通过验证后单独推进；无限循环、多层收藏嵌套、收藏引用收藏、自动采购、跨角色自动调度与对外分享导入暂缓。

### 15.2 数据补充

收藏保存稳定 ID、玩家文本、标签、排序、条目引用、数量、可选操作参数、组合版本和来源关联。系统证据保存其对应的规则版本、旅程、输入与条件，按当前上下文计算展示状态。

库存数量、当前缺料和可执行状态实时计算，不作为跨局永久结论保存。准备区使用现有资源占用规则；已启动行动保存自己的输入快照，不因收藏随后编辑或删除而改变。

跨局收藏与旅程记录采用稳定 ID 关联。导入时不按名称覆盖同名收藏；同 ID 冲突保留副本或明确选择，失效内容引用保留提示而不静默删除。清空旅程不应顺带清空收藏，删除跨局收藏须是独立操作。

### 15.3 新增验收用例

- 将 1、2、3 保存为 A，4、5、6 保存为 B；可以分别改名、打标签、检索、置顶和编辑。
- 单件物品和未验证组合均可收藏；收藏成功不产生物品或隐藏知识。
- 同一件物品属于多份收藏时，库存计数不翻倍，执行仍受唯一资源占用约束。
- 两份同名收藏独立存在；删除任一收藏不删除实物或取消已开始行动。
- “两个甲＋一个乙”及必要步骤可还原；数量与顺序修改后旧验证结论不自动沿用。
- 指定实例售出、损毁或被占用后有正确提示；一键准备不偷偷替换或抢占。
- 缺少材料只提示缺料；点击查看、定位与准备均不执行危险操作或扣除试验材料。
- 不构成单个行动的备料清单仍可整理和查看，不被强制当作无效配方。
- 新局保留自定义整理，但局内结论恢复待验证；固定配方与历史实例分别正确显示。
- 存取档、旅程导入及收藏编辑后，来源、组合版本和执行输入保持可追溯。
- 对照首次试验与重复操作的点击／拖拽次数，确认熟练后操作减少且关键选择仍存在。
