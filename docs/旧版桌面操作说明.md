# 山河问道 · 修真堆叠卡牌（桌面交互 v0.2）

根据「项目企划 v0.3」与「技术文档 v0.1」实现的桌面网页可玩原型。主线是学艺、交游、谋生与调养，音乐和学问均不以战斗胜利为终点。

## 直接游玩

本包包含已经构建的 `dist/`，游玩不需要安装 npm 依赖，只需 Node.js 22.12 或更新版本。

1. 将项目目录放在 `D:\workspace\demo\游戏原型\修真堆叠卡牌`，也可放在其他本地目录。
2. 双击 **启动游戏.cmd**，保持服务窗口开启。
3. 用 Chrome 或 Edge 打开 **http://127.0.0.1:5173**。
4. 关闭服务窗口即可停止。若 5173 端口已有游戏服务，可直接打开该地址。

命令行启动：

```powershell
cd 'D:\workspace\demo\游戏原型\修真堆叠卡牌'
npm start
```

不要直接双击 `dist/index.html`：ES 模块与浏览器存储需要本地 HTTP 服务。更换端口或主机名会切换浏览器存档空间；变更地址前请导出存档。

## 桌面交互 v0.2

本次按《密教模拟器》的桌面操作思路重新实现表现层：自由摆放的卡牌、六个动词方块、可移动的行动窗口、按属性收牌的槽位、计时与手动收取成果。色彩、文字、图案使用本项目自己的修真主题；领域规则及原有内容保持不变。

- 拖卡到槽位，或直接拖到动词方块；也可点击空槽，再点桌面上发亮的卡牌。
- 双击卡牌会投入当前行动的合适空槽；选中卡牌后按 Enter 也可投入。
- 拖动空白移动桌面，滚轮缩放；右下角可以归位或整理卡牌。窗口标题栏也可拖动。
- 卡牌组合只作准备；点击「开始行事」才消耗时间、许可与资源。进行中的卡牌收进行动方块。
- 方块亮起后打开窗口，点击「收取成果」，人物、器物、作品与心得回到桌面。收取只改变摆放，不能重复领取收益。
- 来信会以卡牌出现，也可从底部信件入口打开；选择回应后点击「落定这一选择」。重大来信暂停时间。
- 人物志、宗务、日录、存档是顶部辅助窗口，主玩法始终发生在桌面。

## 第一次游玩

1. 点击「交游」，投入陆青禾与沈知弦，再点击「开始行事」。若要合奏，再放入旧琴和曲谱。
2. 若要学艺，再把旧琴和曲谱放进交游合奏。合奏两次：音律从 8 到 20，信任也会增加。
3. 点击「创作」，放入自己、旧琴和曲谱，完成《江上曲》后收取作品卡。
4. 回应小集邀约。应邀只签约，不立即付款；到「谋生」中放入自己、旧琴和曲谱，按时履约后收到 36 灵钱。
5. 打开「人物志」申请乐修一级。也可把自己与地点卡放入「行游」，去书院求医或药园学习。
6. 卡牌被窗口挡住时，可拖开窗口或拖动桌面；当前行动未收取的卡牌要先收回，才能投入下一项行动。

空格暂停/继续；速度可选 1×、3×、6×。默认每现实秒推进 10 游戏分钟；1 时辰 = 120 游戏分钟。切到后台自动暂停，回来后手动继续。重大事件的暂停须作出选择才能解除。

## 已实现的可玩内容

- 5 个地点、4 位人物、9 类物品、2 项设施、28 项配置行动。
- 习琴、合奏、作品、限时邀约、有限资金合同、演出付款与乐修一级。
- 故人有自己的去处：沈先生可能赴下游，云岚会离开书院，小满也会求你；人物志写处境与秘密，而不只是数值。
- 县志学习与《青溪水道考》独立学问成果。
- 云游医师传授、自学注释、调息、闭关与明确方法的一次性延年记录。
- 药理学习、采药、炼制清和散、普通治疗与丹师/炼气士一级。
- 小组织的加入、有限库存、预算、代理、生产制度、自动轮次与合并异常上报。
- 山道调查与撤离/协商/雇援/承受铃击；普通伤害与特殊摄魂分开判定。
- 真实机会/危险的稳定预感，事实、个人知情与公开评价分开。
- IndexedDB 自动/手动保存、最近五份快照、损坏恢复、导入导出与 Web Locks 单槽写锁。
- 中文自由桌面、矢量插画、属性高亮、键盘替代操作、可保存的卡牌位置与视角。

这是首个可玩原型，不是企划中 80–120 类卡牌、12–18 位 NPC 的完整内容版。详细边界见 [实现与验收说明](docs/实现与验收.md)。

## 开发与验证

```powershell
npm ci
npm run dev
npm run typecheck
npm run content:check
npm test
npm run build
npm run test:browser
npm run test:performance
```

- React + TypeScript + Vite；内容用 JSON，运行时通过 Zod 严格校验。
- 依赖精确版本与锁文件已保存。Node.js 使用 22.12+，本次实际运行 22.21.1。
- 测试配置使用系统 Edge 和独立的 5175 端口，不影响游玩的 5173 服务。其他浏览器可调整 `playwright.config.ts`。
- `npm run build` 顺序执行类型检查、内容检查、领域/存档/会话测试、静态构建。
- 使用 Vite 原生配置加载器，避免受限 Windows 环境中的配置打包访问问题。
- 如果受限环境的 esbuild 依赖预打包报权限错误，可先 `npm run build` 再 `npm start`；生产包已通过真实浏览器验证。
- Vite Node 版本说明：[官方文档](https://vite.dev/guide/)；React 外部状态订阅：[官方文档](https://react.dev/reference/react/useSyncExternalStore)。

## 工程结构

```text
src/domain/          # 纯规则：唯一世界、堆叠、事务、调度、事件、道行、稳定随机
src/content/         # JSON 内容包、严格 schema、引用与操作校验
src/application/     # 唯一命令入口、只读投影、时钟与暂停、保存队列
src/infrastructure/  # IndexedDB、快照封套与校验和
src/presentation/    # React 桌面、人物、药园、存档与内置 SVG 插画
tests/               # 领域、存档、会话、浏览器流程
tools/               # 内容检查、压力测量、无依赖静态服务器
docs/reference/      # 用户提供的技术文档与示例原文
dist/                # 已构建的可玩版本
```

应用界面版本 0.2.0；规则版本 1.0.0，内容版本 0.1.0，存档 schema 1，随机算法 keyed-v1。v0.1 的本地存档与导出文件可直接载入，运行中的行动继续保留。桌面位置、缩放与成果收取状态保存在可选 ui.tabletop 字段，准备槽位在刷新时回到桌面。新版存档含扩展 UI 字段，请在升级前保留一份 v0.1 导出文件用于旧程序回退。

## 道行边界

道行始终从已获职业等级求和，仅影响特殊效果抵抗和趋吉避凶概率。普通学习、疗伤、寿数、职业门槛与实体伤害不读取道行。职业一级需要各自的技能、知识和成果，不能重复领取。
