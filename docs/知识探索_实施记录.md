# 知识、情报与自由探索：原型实施记录

日期：2026-09-21。依据设计计划 v0.2（沿用 v0.1 文件名）。实施前代码检查点：`d2d6b7e`。

本轮交付可玩的三领域切片及个人收藏。P0—P4 的原型功能、P5 的存档与跨局自动检查已落地；同一玩家连续两局的体验、研究成本和点击次数对照仍需真人试玩，不能以自动测试替代。

## 入口与操作

凡尘创角后打开右上方「手札」。主动开启试验坊，不改写原有十条凡尘事件链。

1. 采集／抄录需要 90 分钟，每次取得三份主辅材料；功法抄本可复用。
2. 可直接试验，也可花 1 文、30 分钟打探辅料方向，或花 3 文、60 分钟请散修完整讲解。重复取得同一份情报不会再次收费。
3. 单一主材配基础稳行发现固定方法；主材加一种辅料、选择步骤进入局内试验。普通试验 60 分钟，高强度 90 分钟。
4. 实验开始消耗丹器材料并固定结果；取消不退开工材料。此身同一时间只能参与一项主要行动。界面查看、收藏、定位和准备都不执行。
5. 高强度功法先花 15 分钟试运行，冲突时显示逆行征兆并暂停；停止、降低强度或明确继续。强行冲突扣 8 点健康并产生不适，调息或温脉偏丹可恢复。没有无提示永久损伤。

## 内容目录与规则

| 领域 | 固定方法 | 本局候选关系 | 实际用途 |
|---|---|---|---|
| 炼丹 | 青叶草＋基础稳行 → 基础药膏 | 青叶草＋寒泉液＋缓火，或青叶草＋温灵灰＋逆炼 | 药膏／回元丹恢复健康；养神丹减疲劳；偏差温脉丹解除逆行但增加疲劳 |
| 炼器 | 青铁＋基础稳行 → 调火炉 | 青铁＋白灵晶＋缓火，或青铁＋赤铜＋逆炼 | 调火炉开放丹器逆炼；探灵器开放材料观察；蓄灵器用于调息储备 |
| 功法 | 吐纳篇＋基础稳行 → 收气心得 | 吐纳篇＋行气篇＋先收气，或吐纳篇＋守静篇＋先转脉 | 协同心得开放功法内观；消耗心得用于调息和学识实践；低强度冲突留下观察 |

每个领域独立从两个受控模板生成。丹器两种分布依次为正常／替代／偏差／反应未成：80%／10%／9%／1%，或 45%／45%／9%／1%。功法依据稳定关系结算，不随机出货。这些是原型测试数值，不代表平衡已经验证。

未匹配的丹器组合不产生收益，给出辅料相斥或步骤不合的观察；材料和工具不足、未构成操作时不启动、不扣料。逆炼需要先制作调火炉。三领域采集与固定方法均不要求入宗，核心链不依赖稀有掉落。

规则定义在 `src/content/research.ts`，生成、情报和结算在 `src/domain/research.ts`，共同引用旅程实际规则快照。内容检查验证引用与完整概率，种子检查覆盖两个候选模板与实际可达操作。

## 知识、存档与行动

- 保存实际规则、生成版本、旅程、世界种子、产出随机计数、已固定的行动结果与结算凭据。读取和打开界面不重抽规则或结果。
- 世界生成与试验产出使用不同随机键；付费情报也不推进试验随机计数。
- 显示传闻、已获讲解、试验观察与已验证。功法对相同条件进行复验才标记验证；丹器单次成功不证明产出概率。
- 界面投影移除未知规则映射和进行中结果，已知指引只来自实际证据。道行不参与专业试验。
- 旅程与个人手札分别导出。图鉴、收藏及标明旅程的历史试验存于独立手札记录，和世界保存使用同一 IndexedDB 事务。新旅程保留整理，清空准备区、角色成长与局内证据。
- 按 `AGENTS.md`，可发布版本前不新增旧档迁移；内容版本不兼容时提示新建旅程。

## 个人收藏

支持单卡详情、可见卡牌多选、普通准备区和研究准备区创建收藏；单件物品、清单及未验证组合均允许保存。不因名称含有“必成”等文字授予系统结论。

名称可重复，稳定 ID 区分收藏。支持名称、备注、标签、条目、数量、步骤、强度、种类／实例引用、置顶和手动排序；可按名称、备注、标签和物品搜索，按本局创建／待验证／已有观察筛选。

查看实时计算库存、可用和缺项。准备只取当前可用部分，不采购、不借用、不取消任务、不消耗物品。研究收藏恢复步骤，仍需点击执行并重新检查。普通跨行动清单保持备料清单，不强制解析为单一行动。

实例引用包含旅程与物品身份；耗尽后重新取得同名物品不会重绑。修改组合升版本，保留旧签名和来源；仅改名、备注、标签不改变组合版本。关联试验通过实际输入与条件匹配，历史结果不自动证明修改后的组合。

导入同 ID 冲突保留副本，不按名称覆盖。删除收藏不删除实物、不影响已开始行动。卡牌详情显示引用它的收藏，收藏可定位桌面物品。

## 验证

- `npm run build`：类型检查、正式内容检查和 123 项领域／会话测试通过，生产构建生成。
- `npm run test:browser`：19 项浏览器检查通过，涵盖原有流程、多窗口、拖拽、存取档，以及新增试验、收藏编辑、刷新、跨局图鉴和窄屏准备。
- 256 个确定性种子逐一完成三领域固定方法与合法试验；失败断言携带操作和结果，可用 `seed-N` 复现。
- 单独检查了未获情报的正确操作、道行无加成、重复命令、读档结果固定、重复推进不发奖、危险预警和恢复、旧实例失效、同名收藏与导入冲突。
- 视觉记录：`docs/screenshots/研究-知识与笔记.png`、`研究-个人收藏.png`、`研究-窄屏准备.png`。

生产包仍有 Vite 的单块大于 500 kB 提示，以及依赖库注释提示；构建成功。未为此原型引入新的运行依赖。

## 仍需试玩与后续内容

P5 的真人验收尚未完成：同一人连续两局，对比独行与完整讲解的时间、材料、误判与重复点击，确认新局确实改变决策。当前有失败种子复现、尝试条件和记录，但尚无真人体验结论。
