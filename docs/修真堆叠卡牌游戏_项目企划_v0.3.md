日期：2026年9月20日  
项目名称：待定  
文档用途：确认核心体验、系统边界和首版验证范围；文中的数值与内容数量均为设计提案，尚未经原型验证。

本次修订依据：道行目前只直接参与两类作用——降低针对自己的咒物、摄魂、强制变化等特殊道具效果的生效概率，以及增加趋吉避凶的概率。保留每级职业增加一点道行的规则，并移除旧稿中道行作为突破通用门槛等额外用途。保留旧版供对照，后续设计以本稿为准。道具适用方向已经确认；第6.6节的具体判定、提示方式与数值结构仍为设计提案。

## 0. 创作初衷与项目判断标准

本项目希望呈现一个需要认真生活、专门学习和艰难求道的修真世界。道行高的人可能不擅长战斗；善战者可能不善养生，仍然困于寿数；炼丹、炼器需要各自的知识、手艺与长期实践；儒学、音律可以改变人的生活和理解，却完全不增加伤害或防御。

人物的成就可以体现为延年、治病、完成作品、结交知己、教出学生、维持共同生活、补全学问，也可以体现为斗法与守护。游戏应让这些事情得到相称的篇幅、选择和后续。

**长生本身就是艰难而值得追求的目标。** 玩家需要寻找方法、辨别真伪、照顾身体、解决生计，并在有限岁月中安排学习与人情。职业晋升和道行累计不会自动赠送寿命，更不能使一个人自然精通所有领域。

堆叠卡牌适合这个目标，因为人物、琴谱、书卷、朋友、病痛、季节、传承与承诺都能成为行动的核心对象。一次合奏、一场请教、一段养病和一次斗法可以获得同等清晰的交互与结果呈现。

后续设计采用以下判断标准：

1. 除去战斗奖励，这项活动是否仍有值得参与的过程、成果与后续？
2. 人物的具体本领，能否追溯到实际学习和经历？
3. 高道行人物是否仍有明确的不懂、不善与不能？
4. 玩家能否尊重、依靠一位不善战的人物，并体验一段不以战斗取胜为目标的完整生活？
5. 求取长生是否有独立的困难与方法，而非总等级附带的奖励？

这些原则约束玩法、人物评价、奖励、界面和首版范围，不仅用于背景文案。

## 1. 项目概述

一款以堆叠卡牌为主要交互方式的单人修行人生游戏。玩家扮演具有独特禀赋的修行者，通过求师、学习、劳动、交游、探索和经营获得传承，在一个宗门、散修、江湖势力共同活动的世界中选择自己的道路。

世界与规则融合DND式的多职业、能力前置、角色构筑，以及修真题材的功法、境界、道统、师承和宗门关系。玩家可以长期独行，可以加入宗门专心修炼或争取职权，也可以创建宗门、经营产业、培养弟子。

卡牌呈现人物、物品、地点、功法、情报与事件。组合卡牌就是提出行动，世界根据参与者的能力、关系、资源和当前处境给出结果。

### 1.1 核心体验

> 在有限的岁月中安顿生活、学习本领、结交他人、体悟与求取长生，通过一次次选择形成自己的修行道路。

玩家应当反复遇到这样的选择：

- 我愿意把有限的时间用在怎样的生活、学问与关系上？
- 我现在需要的是生计、健康、传承、理解，还是一个愿意帮助我的人？
- 我是否值得为某个机会离开当前生活，或者承担一份长期义务？
- 这门功法很适合我，但它要求的资源和行为是否可以接受？
- 我应该亲自处理此事，还是交给合适的人？
- 我是否愿意建立一个组织，并为成员的生存与修行负责？

### 1.2 产品定位

| 项目 | 初步定位 |
|---|---|
| 游戏类型 | 堆叠卡牌、角色养成、事件叙事、资源与组织经营 |
| 游戏模式 | 单人；以一个持续存在的主角为核心 |
| 首发操作假设 | PC鼠标操作，支持暂停和时间加速；平台尚未最终确认 |
| 核心受众假设 | 喜欢角色构筑、修真人生、卡牌组合和经营选择的玩家；需要试玩验证 |
| 核心吸引力 | 有限岁月中的求道与生活；专业分工、知己师友、多种有意义的成就 |
| 节奏 | 日常积累与关键选择交替；重要事件出现时允许充分思考 |
| 世界规模 | 先做区域内有联系的人与事，再扩展地域与修行层次 |
| 商业模式、预算、工期 | 暂不确定，待核心原型和制作资源明确后评估 |

### 1.3 已确认方向与本稿假设

**已确认的核心方向：**

1. 以堆叠卡牌承载玩法，参考用户提到的模拟器类卡牌体验。
2. 人物具有基础属性、少量天赋，以及多领域天资。
3. 可以学习多个职业，每获得一级职业等级，人物道行增加一点。
4. 炼丹、炼器、道术、阵法、武术、儒学、天文、音乐等领域均有发展空间。
5. 情报、拜师、宗门招聘、收徒仪式、散修交往、江湖关系与功法获取是重要内容。
6. 邪修通常入门要求较低、进境较快，但资源伦理、敌对风险与心得获取构成代价。
7. 玩家可以选择独狼、加入宗门或创建宗门；交易与管理天资支持产业和宗门经营。
8. 道行、修行年限、战斗能力与各项专业能力不能相互等同，升级不带来全领域自动精通。
9. 长生本身困难，需要专门求索；儒学、音律等可以通过交友、谋生与体悟体现价值，无须具备战斗用途。
10. 道行目前只有两项直接作用：降低针对自己的咒物、摄魂、强制变化等特殊效果的生效概率，以及增加趋吉避凶概率。普通丹药、工具和普通法器效果保持各自规则。

**本稿提出、仍可修改的方案：**人物属性的具体数量、职业目录、道行与境界的分工、时间推进方式、战斗形式、失败规则和首版内容规模。

“秘境模拟器”目前暂按《密教模拟器》这一参考方向理解，具体参考作品尚待确认。本稿的机制均为本项目提案。

## 2. 设计原则

### 2.1 同一个问题允许多种解决路径

获得一门功法，可以通过拜师、宗门贡献、交换、探索、推演或人情。不同路径消耗不同资源，并留下不同后果。

低根骨角色应当可以凭借其他长处建立可持续的发展路线。天资影响效率与适配性，不能把大量角色直接判定为无法游玩。

### 2.2 复杂信息服务于实际选择

属性、天资、关系等信息必须对应可理解的作用。永久信息主要保存在人物面板中，桌面卡牌重点承载能参与行动的对象。

玩家开始行动前，应知道已知条件、预计耗时、占用与消耗的资源，以及可判断的风险。未知部分通过调查逐步揭示。

### 2.3 人与组织具有持续性

NPC拥有目标、能力、资源与关系。宗门拥有传承、产业、成员和制度。事件可以改变这些状态，后续事件读取变化后的状态。

世界变化先围绕当前区域、重要人物和已建立关系进行，保持可追溯性和制作可控性。

### 2.4 三种生活道路持续成立

独行、入宗、创宗各自提供优势和约束。高级资源应存在多种获取方式，避免某个阶段强制玩家转为宗门经营。

组织发展主要增加协调能力和可调动的资源，也带来维持成本、责任与暴露程度。个人修炼仍然需要主角亲自投入。

### 2.5 不以战斗统一衡量价值

不设置用于评价整个人物或整个人生的总战力分数。遇到具体危险时，可以评估其相关能力，但人物总览主要呈现所学、身体状况、经历与关系。

音律不默认附带音攻，儒学不默认附带言出法随。若存在这些特殊传承，需要单独接触、学习与实践；普通学问自身仍有足够完整的内容。

道行只直接参与特殊道具生效与趋吉避凶两类判定。具体修法的本领由该方法的学习和实践决定，没有来自总道行的全属性倍率。专业间的协同需要解释清楚，悟性或神识较高只能帮助学习与操作，不能替代丹方、材料知识和实际经验。

### 2.6 堆叠的对象体现玩家在做什么

“自己＋琴谱＋琴＋练习”与“自己＋剑谱＋练习”共享行动框架，各自产生对应知识和成果。“朋友＋琴＋合奏”与“师父＋疑难＋请教”则通过不同互动改变关系和理解。

组合卡牌不仅是消费资源的配方，也表达参与者、目的、方法与处境。生计、创作、交游、照护与修行需要和战斗一样清楚的反馈与持续内容。

## 3. 世界观与玩家身份

### 3.1 世界基础

世界由凡人城镇、江湖社会、修行宗门、散修网络和特殊修行地点共同组成。修行传承既可能掌握在大宗门中，也可能藏于家学、手艺、地方祭祀、残卷与个人经历之中。

诸道并存。炼气、武学、丹器、儒学、音律等道路都能建立有价值的修行成果。洞天、异域、神祇和古代道统可作为后续扩展空间。

DND式设计主要体现为多职业组合、职业能力、特殊天赋、前置条件与行动检定；具体规则为本项目设计，不预设照搬某一版规则书。

### 3.2 三条长期道路

| 道路 | 核心玩法 | 主要优势 | 持续约束 |
|---|---|---|---|
| 独狼散修 | 访师、探索、交换、个人洞府经营 | 灵活、隐蔽、义务较少，自行决定修炼方向 | 资源与传承不稳定，缺少组织支援 |
| 加入宗门 | 获取身份、履行义务、学习传承、参与派系与职位竞争 | 设施、传承、同门、保护与稳定任务 | 门规、贡献、竞争、师承和政治关系 |
| 创建宗门 | 建立驻地与生计、招收成员、培养传承、处理对外关系 | 制定方向，组织分工，形成长期影响 | 维持费用、人才流失、成员诉求与外部压力 |

身份允许转换。脱离宗门、另立门户、重新入宗等行为，需要处理原有承诺、财产与传承约定，历史关系持续保留。

### 3.3 人生目标

长期目标可以包括修成某种道果、成为一代宗师、补全失传功法、建立稳定道统、完成私人使命等。玩家可以选择阶段性目标，不要求所有结局依赖最高境界。

寿数、健康和求取延年的机会进入核心规则。寿命耗尽后的结局、永久死亡、继承玩法和跨局成长仍待确认，原型阶段优先支持保存与继续游玩。

## 4. 核心循环与时间

### 4.1 短期循环

获取消息或发现需求 → 判断自身条件 → 准备资源与人手 → 堆叠卡牌执行行动 → 获得成果与后果 → 调整下一步安排。

短期行动包括谋生、采购、交流、练习、短途探索与处理关系。

### 4.2 中期循环

发现愿意投入的学问或生活目标 → 接触人和方法 → 学习、实践与经历 → 形成作品、关系或理解 → 获得新的生活与修行可能。职业晋升是其中一类结果。

中期目标包括成为正式弟子、学会一套丹方、解决师父的困难、稳定一项收入、突破境界等。

### 4.3 长期循环

形成个人道路 → 选择组织关系 → 调动更大范围的资源 → 承担更深的义务与冲突 → 完成个人或组织目标。

### 4.4 时间与占用

- 建议采用可暂停的连续时间，行动以游戏日等单位计时；具体时间比例待测试。
- 一个角色同一时间只能亲自承担一项主要行动。出行、修炼、作战与亲自生产互相占用。
- 已经委托他人执行的任务可以并行，但必须有实际参与者、资源与条件。
- 距离影响旅行、运送与消息到达；同一个角色不能同时出现在两个地点。
- 重要事件自动暂停。阅读、规划和调整界面时可以停下世界时间。
- 招募仪式、灵植成熟等使用明确期限；闭关前提示即将错过的已知事项。
- 取消行动的损失由行动类型决定，并在开始前说明；特殊中断风险另行标注。

时间成本体现为生活开支、机会变化、伤势恢复、关系发展、寿数与世界事件。玩家暂停思考不会消耗游戏中的岁月。

### 4.5 长生、健康与有限岁月

年龄、身体状况、慢性损伤和已掌握的延年方法分别记录。具体数值及寿数显示精度待测试，不预设人人都知道自己的准确死期。

养生、治疗、丹药和修持可以作用于不同环节：恢复健康、减少损伤、延缓衰老或真正延长寿数。各效果需要明确区分，同一种方法不能无条件重复叠加。

长生路线需要可靠的方法、适合自身的条件、实践和理解。金钱与人情可以帮助接触知识、改善条件，但不能直接购买无限寿命。道行不作为延寿的通用门槛，也不直接提高延寿成功率；趋吉避凶可以让人注意到有关机会，真正能否延年仍由具体方法和条件决定。

时间有限会产生取舍，但节奏应允许访友、学艺和生活。避免用过紧的寿命倒计时迫使玩家放弃所有没有即时收益的活动。游戏需要同时支持求道的紧迫感和人愿意度过的日常。

首版必须验证一次与健康、寿数或延年方法有关的实质选择；完整衰老阶段和寿终规则可以随后深化。

## 5. 人物系统

### 5.1 六层人物结构

| 层次 | 作用 | 变化方式 |
|---|---|---|
| 基础属性 | 当前身体与精神条件 | 对应训练、具体功法、衰老、健康和伤势等；无通用升级全加成 |
| 天赋 | 少量改变玩法规则的特殊禀赋 | 出身获得，少数重大经历可能增加或改变 |
| 天资 | 对应领域的学习效率与适配性 | 以先天差异为主，特殊经历可有限改变 |
| 职业等级 | 已取得的修行成果与职业能力 | 达成晋升条件后提高 |
| 功法与技艺 | 实际会使用的招式、方法和知识 | 学习、实践、指点、推演 |
| 身份与关系 | 社会位置、信任、义务和接触渠道 | 行为、任命、契约、事件 |

生命、法力、疲劳、伤势等属于当前状态，单独显示。

### 5.2 基础属性提案

| 属性 | 主要影响 |
|---|---|
| 筋力 | 发力、负重、部分近战与生产行为 |
| 身法 | 移动、闪避、潜行与精细身体动作 |
| 体魄 | 生命、耐力、恢复与身体承受力 |
| 根骨 | 吐纳适配、灵气承受、部分功法与突破条件 |
| 悟性 | 理解陌生知识、推演、融会贯通 |
| 神识 | 感知、施法操控、精细炼制与神魂活动 |
| 心性 | 专注、自制、承受威压与维持长期修行 |
| 气度 | 第一印象、表达、号召及部分社会行动 |

属性无法替代知识和身份。例如气度高可以改善交谈，但不能自动获得宗门秘传；根骨高也不能替代炼丹学习。

### 5.3 天赋

开局建议拥有1—3个显著天赋。天赋强调特殊能力、独特路径或附带约束，不按每个职业等级大量发放。

| 示例 | 效果方向 |
|---|---|
| 百草通感 | 接触鲜活灵植时可以察觉药性，开启特殊辨药行动 |
| 闻弦知意 | 合奏时感知部分情绪，可能发现隐藏话题 |
| 经脉异构 | 普通行气法存在适配问题，但可修习罕见运行路线 |
| 过目留痕 | 短暂阅读可留下残缺记忆，日后有机会补全 |

天赋的收益与代价应在相关行动中体现，避免只是无法感知的小幅数值变化。

### 5.4 天资

| 类别 | 领域示例 |
|---|---|
| 道术 | 五行、雷法、幻术、御魂等 |
| 修行技艺 | 炼丹、炼器、阵法、符箓、医术 |
| 武学 | 拳掌、兵刃、身法、御剑 |
| 学问 | 儒学、天文、音乐、考据 |
| 世务 | 交易、管理、交际 |

天资主要影响学习成本、获得有效心得的效率和部分复杂方法的适配条件。实际行动成果还取决于职业能力、熟练度、工具与准备。

一次行动指定主要领域，必要时使用一个辅助领域。例如炼制火属性丹药以炼丹为主，火法只帮助控火。避免多项相关天资层层乘算。

具体天资数量与数值范围待原型测试。界面可以先呈现等级描述，并支持查看详细影响。

### 5.5 NPC与人才价值

主角、重要NPC与宗门成员使用一致的人物结构。NPC另外具有个人目标、偏好、家庭或师承联系，以及愿意承担的工作范围。

低根骨、高管理的成员可以成为优秀总管；炼丹天资高但心性浮躁的弟子需要不同培养方式；高修为长老可能重视闭关时间，不愿承担日常事务。

任命必须考虑能力、意愿、权限与资源。关系改善可以推动合作，但不能无限替代个人目标和利益。

## 6. 职业、道行与境界

### 6.1 不变的成长规则

**人物道行＝该人物已经获得的全部职业等级之和。每获得一级职业等级，道行增加一点。**

例如：剑修4级＋丹师2级＋儒修1级＝道行7。

职业等级记录修行成果。更换身份、离开宗门或停止使用某门功法不会让已获得等级重新成为可领取奖励；转修时不能重复结算旧等级。

### 6.2 道行、本领、境界与寿数分别处理

| 成长维度 | 负责的内容 |
|---|---|
| 总道行 | 按职业等级之和累计，只直接影响特殊道具生效概率与趋吉避凶概率 |
| 职业等级 | 对应能力深度、专业权限、可掌握的方法 |
| 具体技艺 | 实际能否完成炼制、演奏、论学或战斗等行动，以及完成质量 |
| 境界 | 特定修持获得的阶段成果及其明确效果；不同传承的效果另行定义 |
| 寿数与健康 | 尚能度过多少岁月的条件及身体状态，由具体方法和经历改变 |

境界突破要求相应传承的准备、实践和理解，不额外设置总道行门槛或总道行成功率加成。各条道路是否使用同一境界命名体系仍待确定，不能用一张统一等级表替代实际所学。

战斗读取实际掌握的战斗方法、身体条件、临敌经验、装备、环境与准备。道行不会直接增加攻击、防御或命中；遇到明确受道行影响的特殊道具时，才按该效果的规则参与判定。趋吉避凶也可能让人物在交战前获得避开危险的机会，这些影响不等于全面提高战斗能力。

一位专注养生、寿数绵长的道人可能需要别人护送；一位擅长搏杀的人也可能因旧伤而命不长久；丹师不会因为总道行提高就自动学会炼器。这样的差异应在行动条件中成立。

### 6.3 职业晋升流程

接触学问或传承 → 学会基础方法 → 完成实践 → 形成相应理解 → 满足该职业的晋升条件 → 获得职业等级与一点道行。

本版取消“总道行越高，学习任何新职业都需要更昂贵的统一经验”的默认方案。求取新学问的困难主要来自该领域、学习条件和有限时间。

- 职业晋升要求该领域的知识、实践与理解，成本由具体级别和方法决定。
- 天资、师资、工具与已有相关知识影响学习效率；高道行不使陌生专业自动精通。
- 同一门职业的同一级成果只结算一次，不通过改名或重复入门获得道行。
- 多学几个入门职业可以增加道行，并只带来规定的两项概率变化，不会自动获得高阶技艺、直接攻防加成或寿命。
- 兼修受到时间、投入和知识深度的真实约束；专精可以完成对应领域更困难的事情。
- 深入学问与广泛涉猎都可以形成有价值的人生，不预设必须有一个总收益最优的构筑。

原型需要检查重复奖励和取巧绕过实际要求的问题，同时保留跨领域学习的乐趣。具体晋升条件与成本仍为待验证提案。

### 6.4 职业与学问的关系

| 职业方向 | 常用学问与技艺 | 玩法作用 |
|---|---|---|
| 炼气士 | 吐纳、养生、心法、具体道术 | 调养、求取延年、理解修持；各门道术另行学习 |
| 武修／剑修 | 武术、炼体、兵刃或御剑 | 战斗、护送、身体突破 |
| 丹师 | 炼丹、医术、辨药 | 丹药、诊治、药材利用 |
| 器师 | 炼器、材料、部分阵法 | 制作、修复、改造法器 |
| 阵师 | 阵法、地理、天文 | 布阵、破阵、保护与经营据点 |
| 儒修 | 经义、礼法、考据、讲学与践履 | 授业谋生、论学交友、调解、著述与体悟 |
| 乐修 | 演奏、音律、谱曲、合奏与聆听 | 演出谋生、结交知音、创作传授与体悟 |

一门学问可以被多个职业使用。器师可以学习剑术，武修可以学习交易。普通手艺熟练度提高不会自动增加道行，正式职业晋升始终按每级一点结算。

交易、管理首先作为所有人物可用的天资与技艺存在。是否进一步设置商道、经营类修行职业，列为后续设计决策。

儒学、音乐既有普通学艺，也可以形成修行道路。熟练演奏与获得某种修行理解各有条件，不能把每次演出直接计成通用修炼经验。音攻或以文施术若存在，属于专门传承，不是普通学者与乐师自然获得的能力。

### 6.5 功法与知识

功法记录来源、完整度、适用条件、学习要求、运行方式与已知后患。功法可以通过师授、书籍、交换、探索与推演获得。

获得文本不等于理解；理解不等于熟练；熟练也不等于已满足全部施展条件。人物面板与行动提示应清楚区分这些状态。

残缺功法可以提供研究目标，但关键风险应有可发现的征兆。长期修炼成功不能单纯取决于玩家猜中隐藏配方。

### 6.6 道行的两项直接作用

**已确认的规则边界：每级职业增加一点道行；道行目前只直接参与以下两类判定。** 以下将趋吉避凶优先实现为预感与机会提示，属于本稿的设计建议，具体表现可以继续调整。

#### A. 降低针对自己的特殊道具效果的生效概率

适用于咒物、摄魂、强制变化等干预人物的特殊效果。是否受道行影响写在具体效果规则中，不能仅因为物品属于法器，就让整件物品失效。

| 情况 | 道行的作用 |
|---|---|
| 咒物试图在目标身上种下诅咒 | 道行越高，诅咒附着成功的概率越低 |
| 摄魂铃试图拘摄目标魂魄 | 道行越高，拘摄成功的概率越低 |
| 特殊道具试图强制改变目标形态 | 道行越高，变化成功的概率越低 |
| 法器造成实体打击，并附带摄魂效果 | 实体伤害按战斗规则处理，摄魂部分单独读取道行 |
| 使用普通药物、工具，接受正常治疗 | 按药效、工具和治疗规则处理，不因道行高自动失效 |
| 普通刀剑攻击、火焰伤害或材料毒性 | 不因总道行获得通用减伤或免疫；依靠具体防护与处理方法 |

建议先检查道具能否满足目标、距离、媒介等使用条件，再根据效果强度、仪式准备和目标道行判断是否奏效。道具威力与操作者自身道行不默认绑定；强大的特殊道具仍可能威胁高道行人物。

原型先验证概率随道行单调下降、收益逐渐减缓的形式。没有一条“道行达到某值就免疫所有特殊道具”的通用规则。若某种具体传承确有免疫或破解能力，单独写明来源与范围。

生效概率与生效后的持续时间、伤害、解除难度分别处理。本阶段道行只改变上述效果的生效概率，不再悄然附加缩短持续时间或提高反噬对方概率等第三类收益。

#### B. 增加趋吉避凶的概率

建议优先表现为对既存机会或危险产生预感，给玩家一个可以采取行动的窗口。道行越高，相关事件触发这种窗口的概率越高；不保证每次遇险都能察觉。

| 情境 | 卡牌或事件表现 | 玩家仍需作出的选择 |
|---|---|---|
| 即将前往可能遭遇伏击的山道 | 出现针对该行程的“心中不安”提示 | 打听、侦察、结伴、改道或照常前往 |
| 即将接触来历异常的物品 | 察觉“不宜贸然触碰”，但未辨明原理 | 请人鉴定、隔离、放弃或继续试探 |
| 经过存在求学机会的地点 | 产生值得停留、打听的感应 | 投入时间接触当地人物与活动 |
| 一次会面可能开启适合自己的道路 | 感到与此事有缘或值得细谈 | 实际交流、建立关系并满足机会条件 |

预感提供有限信息，不能直接揭示凶手、隐藏数值、道具全部属性或所有未来结果。辨伪、侦察、医术、天文等专业仍然有独立用途。

趋吉需要有真实存在的机会作为依据，不凭空生成宝物；避凶提供退路与选择，不把已发生的刀伤自动改成未命中。玩家忽视预警后，后果按实际行动处理。

若以后希望加入偶然错开危险等表现，仍归入这第二类规则，并需要单独确定事件范围和结算方式。当前不默认给所有行动附加幸运重掷、生产成功率、交易折扣或掉落加成。

#### C. 两项作用的关系与结算边界

预感到咒物的危险与实际抵抗咒物，是先后不同的环节。玩家可能提前避开，也可能坚持接触后抵抗成功；同一个环节不因为同时采用多个名称而重复领取道行加成。

对同一未发生实质变化的事件保存一次预感结果，不通过重复打开、移出移入卡牌或读档无限抽取提示。道具再次尝试应符合其消耗、时间与可重复使用规则。

道行不等于道德。正道、邪修与普通NPC遵守相同判定；某人的恶行、被追查程度和他是否察觉危险分别记录。

暂不新增第三种直接作用，也不把道行作为学习、延寿、境界突破、宗门职位或通用任务权限的数值门槛。具体学问与社会身份由各自的知识、实践、关系与条件决定。

## 7. 堆叠交互与桌面组织

### 7.1 卡牌类型

| 类型 | 示例 | 用途 |
|---|---|---|
| 人物 | 自己、师父、同伴、执事 | 行动参与者、交谈或关系对象 |
| 地点与设施 | 茶馆、宗门、洞府、丹炉、药园 | 行动场所与生产条件 |
| 物品与资源 | 灵石、药材、法器、礼物 | 消耗、装备、交易与投入 |
| 知识 | 功法、丹方、阵图、疑难 | 学习、制作、推演与请教 |
| 身份与凭据 | 推荐信、弟子凭证、契约 | 解锁接触、权限与承诺 |
| 情报与事件 | 招募消息、求助、追查线索 | 提供机会、期限与问题 |
| 行动与项目 | 修炼、访友、炼制、经营安排 | 汇总目标、输入、过程与结果 |

### 7.2 统一操作语法

**参与者＋对象或地点＋方法／凭据＋可选投入 → 行动项目 → 成果与后果。**

| 组合 | 行动与结果示例 |
|---|---|
| 自己＋茶馆＋打听＋碎银 | 获得带有来源与时效的消息 |
| 自己＋招募告示＋技艺证明 | 获得试工、职位或具体拒绝理由 |
| 自己＋散修＋礼物 | 交谈、委托、戒备、指点或进一步关系 |
| 自己＋残卷＋推演 | 理解进展、疑难、残缺记忆或风险征兆 |
| 自己＋丹炉＋丹方＋药材 | 炼制成果、副产物、损耗与心得 |
| 自己＋琴＋谱本＋练习 | 演奏进展、具体疑难与对曲意的理解 |
| 自己＋友人＋琴＋合奏 | 一次共同经历、作品变化与关系发展 |
| 自己＋经义疑难＋老师＋请教 | 理解、分歧、阅读线索或实践建议 |
| 自己＋行程＋已触发的祸福预感 | 查看相关迹象，选择调查、结伴、改道或继续 |
| 执事＋药园＋经营方针 | 持续生产并在异常时请求处理 |

### 7.3 行动可读性

拖入卡牌时提示可参与的行动。组合存在多个合理结果时，显示可选择的方法。

开始前展示：参与者、必要条件、预计时间、资源占用、实际消耗、已知收益和风险。未知消息以“未经证实”等方式标记，不使用虚假的精确概率。

失败应提供可理解的原因。部分行动失败仍可留下经验、线索或关系变化。

### 7.4 卡牌数量控制

- 属性、天资、职业与长期关系记录保存在面板中，按需展开。
- 同类材料可以合并计数，常用配方可以收藏与复用。
- 地点、储物、人物与进行中项目有稳定的收纳区域。
- 一张人物牌代表唯一角色，复制展示不能复制行动能力。
- 资源在项目开始时明确锁定或消耗，防止同一物资供给多个项目。
- 历史事件进入可追溯日志；当前仍有用途的消息继续保留。

## 8. 社会关系与事件系统

### 8.1 入道与传承路径

| 路径 | 进入条件 | 收益 | 后续内容 |
|---|---|---|---|
| 收徒仪式 | 获取消息、按时到场、参与考核 | 正式身份与系统培养 | 同门、师承、考核、派系 |
| 杂役应聘 | 职位空缺、工作能力或推荐 | 生计、设施接触、晋升机会 | 工作问题、管事关系、转入培养 |
| 散修拜师 | 相遇、互信、双方需求匹配 | 个性化指点、独门方法 | 师父目标、资源短缺、私人恩怨 |
| 江湖交往 | 护送、行医、比武、赴宴等 | 武学、消息、人情与地方支援 | 帮派纠纷、故人、承诺 |
| 自寻传承 | 购买、探索、交换、考据 | 较自由的知识组合 | 辨伪、残缺、推演、追溯来源 |
| 秘密传承 | 黑市、隐秘引荐、特殊机缘 | 罕见或禁忌方法 | 保密、控制、代价与追查 |

### 8.2 情报本身有玩法

消息至少记录来源、地点、期限、已知程度。玩家可以核实、转交、利用或暂时搁置。

重要机会不只依赖单次随机抽取。收徒仪式等内容应有多个获取线索的渠道；主动打听可以提高找到相关信息的机会。

道行产生的预感是一种额外发现窗口，不取代打听与调查。低道行人物仍可以依靠知识、观察、准备和朋友找到机会、规避危险。

同一消息针对不同人物产生不同用途。宗门扩招可能是拜师机会，也可能意味着采购需求、人才竞争或内部动荡。

### 8.3 事件链结构

**线索 → 接触 → 机会或冲突 → 选择与检定 → 状态改变 → 后续事件。**

每个事件配置参与者、触发条件、期限、可用解法、成本、结果与后续条件。事件先满足世界状态与人物关系，再在适合的候选中抽取。

事件可包括：谋生、师承、修行疑难、同门交往、经营异常、地区变化、探索、私人恩怨及重大危机。

事件需要冷却与优先级，避免连续打断修炼。组织经营后，普通事务由受托者解决，只将重要异常提交给玩家。

### 8.4 关系的具体含义

关系至少区分熟悉程度、信任、利益联系和未履行承诺。对外展示优先使用可理解的描述与具体事项，避免铺满数值。

拜师需要双方条件匹配。师父可能需要继承人、助手、资源或可靠的同行者；玩家的天资只是考虑因素之一。

善意、履约、共同经历、欺骗与伤害会留下记录。不同NPC可以对同一行为作出不同评价。

### 8.5 失败后的延续

落选可以认识其他落选者，试工失败可以暴露知识短板，炼制失败可以产生有用疑难。失败也可以损失资源、恶化关系或造成伤势，但不应普遍切断所有发展路径。

### 8.6 学问与生活需要自己的事件内容

每个重点领域至少要有学习过程、日常用途、与人共同参与的活动，以及值得长期追求的成果。篇幅与制作质量不能完全按照战斗贡献分配。

| 领域 | 可以反复参与的内容 | 长期成果示例 |
|---|---|---|
| 音律 | 请教、练曲、受邀演出、合奏、采风、修订谱本 | 完成作品、形成风格、结交知音、教出学生 |
| 儒学 | 读书、讲学、考据、论辩、调解、践行主张 | 注疏、学说、学生、信任，以及经过经历修正的理解 |
| 天文 | 观测、记录、校验历法、预测节候、交流观测 | 星历、观测传统、地方生产服务与对时序的认识 |
| 炼丹 | 辨药、试方、诊治、制药、交流失败记录 | 稳定丹方、治疗方法、受助者与同行认可 |

收入来自实际需求、质量、委托和当地条件。友谊通过共同经历、兴趣、互相帮助与分歧建立，不把每个人都做成可以兑换资源的关系入口。

### 8.7 体悟有内容与适用范围

体悟应记录“因为什么，对什么有了怎样的理解”。例如合奏中发现一味抢拍破坏了全曲的呼应；教学时发现原先自以为懂得的道理无法说明。

这样的经历可以先形成疑难或心得，再通过反思、实践、交流与已有所学联系起来。它可能推动相关职业晋升、解决某个修持困惑，或者只改变人物的认识和关系。

重复演奏同一首曲子可以积累熟练度，但不能保证每次产生新的道悟。不同经历不统一折算为可以购买任何能力的“感悟点”。具体跨学问联系需要内容设计支持。

一次相聚、作品完成或故人重逢也可以自身构成事件成果，不必每次附送钱、属性或道行。

## 9. 产业与宗门经营

### 9.1 个人、产业、宗门三个规模

| 规模 | 交易发挥作用 | 管理发挥作用 |
|---|---|---|
| 个人生活 | 判断行情、议价、交换功法、建立供货关系 | 安排雇工、组织短期队伍、经营个人洞府 |
| 产业经营 | 采购、销售、商路与合作契约 | 人员安排、维护、训练、损耗与纠纷处理 |
| 宗门经营 | 长期供给、商业伙伴、资源封锁应对 | 任命执事、协调部门、分配资源、落实制度 |

天资影响学习与解决问题的效率。实际成果还取决于技能、当地信息、受托人、权限与投入。高交易能力仍然需要了解市场，高管理能力仍然需要可执行的安排。

### 9.2 加入宗门后的选择

玩家可以保持普通成员身份，以贡献换取培养；也可以担任职务，逐步取得组织权力。

| 身份或职务 | 可参与事务 |
|---|---|
| 杂役、学徒 | 承担工作，积累熟练度与接触机会 |
| 正式弟子 | 获取培养，完成任务，选择师承 |
| 执事 | 管理具体产业或一组人手 |
| 长老 | 传授学问，培养弟子，参与重要决策 |
| 掌门 | 协调宗门方向、人事和对外事务 |

这些职位是通用示例。不同宗门可以采用不同制度；职位变化也不要求所有玩家走同一条晋升阶梯。

修为、地位与经营能力分别计算。高修为长老可能没有组织意愿，低修为执事也可能拥有重要经验与人脉。

### 9.3 创建宗门

创建组织需要具备可居留与活动的驻地、能吸引成员的条件、基本供给，以及当地立足的办法。

吸引成员的条件可以是传承、资源、庇护、声望或共同目标。对小规模组织，不要求一开始就拥有完整设施和大量土地。

早期形态可以是一个师父、几名弟子、一处洞府和一座丹炉。玩家可以选择长期保持小规模，也可以扩展为拥有多个产业和部门的宗门。

### 9.4 宗门的基本构成

| 构成 | 内容 |
|---|---|
| 传承 | 已保存和允许传授的知识、师资、培养条件 |
| 成员 | 能力、目标、关系、待遇与当前职责 |
| 资源 | 资金、材料、储备、持续收入与义务 |
| 设施 | 驻地、工坊、药园、藏书、修炼与防御设施 |
| 制度 | 招收条件、分配办法、传法条件、任务与奖惩 |
| 对外关系 | 商业往来、盟约、恩怨、地区声望与威胁 |

宗门不凭空产生收益。生产消耗人手、材料、维护与时间；资源点需要守护，贸易需要需求与运输，成员需要生计与成长机会。

### 9.5 培养与分工

弟子培养包括基础教学、实践安排、资源支持和职业选择。玩家可以按天资安排方向，也可以尊重成员志向，以获得不同合作结果。

管理过程应提出具体问题：丹房缺少熟练助手，药园损耗异常，执事无力协调两位长老，新弟子对资源分配不满。玩家通过调查、任命、训练、调整规则或亲自处理解决问题。

关系、意愿和个人目标影响履职与留任。组织规模扩大之后，不能把全部人物简化成无条件服从的产能。

宗门的声誉按受众与领域形成：有人因善于救治而受尊敬，有人以传授学问著称，有人拥有强大的护卫能力。讲师、乐师、医者和管事可以凭实际贡献获得资源与地位。

安全确实需要安排，但可通过护卫、盟友、避险、地理条件和当地关系处理。不能要求每位成员都成为战斗人员，或把所有组织成果统一计入军事排名。

### 9.6 委托与自动运转

每项持续事务指定负责人、工作目标、资源额度与异常上报条件。负责人在权限内处理日常事项，超出权限或遇到重要风险时形成事件卡。

玩家在宗门阶段主要决定人事、预算、培养与方向。主角闭关时，宗门可以继续运行，但必须提前安排代理人和资源。

### 9.7 独行路线的长期保障

高阶资源可以通过交易、互助、租用设施、探索、委托或临时合作取得。独行者拥有较低维持成本和较少组织义务，但需要处理供给不稳定与外部依赖。

个人洞府、雇工和临时同伴不自动等于创建宗门。玩家是否招收弟子、建立共同身份和持续组织责任，应当是明确选择。

## 10. 正邪路线与禁忌修行

### 10.1 邪修的吸引力

部分邪道方法可以绕过根骨、资源渠道或常规积累要求，加快某项修持或取得特定能力。它应当真实解决玩家正在面对的问题，而后续代价由功法要求和具体行为逐步产生。

诱惑可以来自寿数将尽、病痛难治、传承难求或想保护重要的人。一门禁法可能擅长续命却不善斗法，另一门可能提高杀伤却严重损身；“进境快”必须说明进的是哪一种修持，不能统一理解为全方面变强。

不同传承的代价不同，并非每门邪道功法都同时具有侵蚀、依赖、伤害和追杀。

### 10.2 五类持续压力

| 压力 | 机制 |
|---|---|
| 特殊资源 | 深入修炼后需要更稀缺、难以公开获得的材料 |
| 伤害与仇怨 | 受害者及其关系人产生求助、调查、报复等行动 |
| 暴露与追查 | 目击、交易记录、遗留痕迹、功法特征逐步形成证据 |
| 心得稀缺 | 修习者少、互不信任、经验难验证，师父可能隐瞒关键内容 |
| 功法后患 | 部分传承出现反噬、依赖或侵蚀，需要具体应对 |

心得可以通过实验、交换、旧记录或师承获得。有组织的邪道可能提供完整培养，但附带更强的控制与义务。

### 10.3 分开记录行为、信息与评价

“实际做过什么”“哪些人知道”“这些人如何评价”分别处理。隐秘伤害不会令所有正道角色立即知晓，但受害事实、证据与调查持续存在。

宗门标签不能完全代替行为判断。某些传承被禁止是因为伤害，某些源于利益或历史冲突。正道组织也可能存在腐败与内部争议。

是否存在客观生效的业力、天谴等规则，列为世界观待定项；首版优先使用可观察的人物与组织后果。

### 10.4 替代资源与改良

部分功法可以使用代用品，但需要牺牲效率、增加成本或承担其他困难。替代途径必须符合该功法的原理，不为所有伤害行为提供无成本替换。

研究改良可以形成长期目标，要求知识、实验和支持。停止使用、封存或转修也是选择；此前产生的伤害与承诺不会自动消失。

## 11. 战斗、探索与风险处理

### 11.1 战斗的职责

战斗处理争斗、护送、危险遭遇等问题，检验相关技艺、准备和环境利用。它可以产生伤势、战利品及特定群体中的名声，但不作为所有人生道路的最终考试。

首版必须存在不依赖赢得强制战斗也能推进的完整目标。危险可以选择回避、协商、雇人、结伴或放弃某个机会；这些方法有自己的成本和条件。

原型优先采用短流程、可干预的遭遇形式，具体表现待验证。

建议流程：侦察或遭遇 → 确定目标 → 配置人物、方法与资源 → 分阶段处理 → 选择继续、调整或撤离。

目标可以是击退、拖延、逃脱、夺取物品或保护对象。相关阵法、丹药、谈判与人情可以改变遭遇条件。音乐和儒学的普通熟练度不默认提供战斗效果；若某种具体方法确有此作用，需要单独学习并解释其条件。

### 11.2 检定原则

- 条件满足且无实质风险的普通事务直接完成。
- 有风险的行动读取主要能力、知识、准备、环境和对方状态。
- 随机变化用于表达不确定性，不能掩盖关键条件缺失。
- 已知风险展示依据；情报不足时展示未知范围或风险描述。
- 战斗失败可造成伤势、被迫撤退、失物或被俘；致死规则待确认。

### 11.3 探索内容

探索由地点线索、出行准备、局部事件和结果组成。不同职业可以发现不同用途的事物，例如阵师识别旧阵，器师辨认残器，儒修读懂碑文。

探索所得可以回流到传承、生产、关系与经营，而不只增加战斗装备。

## 12. 首版体验示例

以下是用于验证系统衔接的情境提案，并非固定剧情。

### 12.1 开局人物

主角根骨平庸，炼丹与交易天资出众，管理天资良好，拥有“百草通感”。起点是一座邻近修行宗门的县城，携带少量生活资源。

### 12.2 获取机会

在茶馆打听到宗门收徒、药园招工和一位散修求药三条消息。玩家可以花时间核实，准备考核，尝试工作或寻找散修。

### 12.3 形成关系

玩家应聘药园后发现病株。可以自己研究，向管事报告，或者向认识的医师求助。处理方式影响药园状态、信任、个人收益与后续接触。

### 12.4 学习与晋升

借助工作、师授或交换获得基础炼丹方法，完成实践并解决疑难，取得丹师一级，道行增加一点。与此同时，可以学习交易和辨药等普通技艺。

### 12.5 形成不同人生方向

| 选择 | 后续目标 |
|---|---|
| 留在宗门 | 获得正式培养，选择做专业弟子或争取丹房事务 |
| 跟随散修 | 建立私人师承，帮助师父寻找药材或解决旧事 |
| 保持独行 | 租用丹炉，交换丹方，经营个人收入与洞府 |
| 尝试组织 | 邀请少量合作者，以工坊和教学逐渐建立小型道统 |
| 接触禁术 | 获得更快进境的方法，同时面对材料来源和后续追查 |

这些选择可以交织。玩家不需要在开局按下一个永久锁定人生路线的按钮。

### 12.6 经营阶段的单独验证

为了尽早评估管理玩法，开发期设置一个可直接载入的经营测试存档：主角管理一处药园、一座丹炉和数名能力不同的成员，面对供给、培养与关系问题。

该存档用于开发和试玩验证，不意味着正式游戏强制跳过成长过程或要求玩家创建宗门。

### 12.7 音律与求道的完整体验样例

另一个预设人物擅长音律，战斗能力普通，希望在维持生计的同时寻找可靠的延年方法。

他先通过受雇演奏获得生活收入。一次合奏暴露了自己听取他人演奏的不足，形成需要练习和请教的具体问题；合作者可能成为友人，也可能因风格分歧暂时分开。

经过学习与共同创作，玩家可以完成谱本、得到持续演出邀约，或培养一个学生。这些都能作为阶段目标的成果，不要求随后获得战斗绝技。

在一次访友中，玩家接触到养生传承的线索。友人是否愿意介绍，取决于实际信任、双方处境与传承要求。获得线索后，仍需辨明方法、学习调养、承担时间与资源投入。

曲艺进步不会自动延寿。只有当某次理解确实与已学修持产生具体联系，并经过后续实践时，才可能帮助解决相应问题。玩家也可以始终把音乐作为生活与友谊的重要部分。

这条体验至少包含一次作品或关系成果、一次真实的生计选择，以及一次涉及健康、岁月或求取延年的决定。没有强制战斗胜利条件。

## 13. 首个可玩版本范围

以下数量作为制作规模估算的起点，可以根据原型反馈缩减。首版目标是形成完整的选择与后果，正式版再扩展内容量与境界。

| 模块 | 首版建议范围 |
|---|---|
| 地域 | 一座县城及周边少量节点，包含集市、茶馆、野外与驻地 |
| 组织 | 两个具有不同培养与经营特点的宗门，一组地方江湖关系 |
| 特殊师承 | 至少一条散修师承、一条邪道或禁忌传承 |
| 重要人物 | 约12—18名具有目标与事件联系的命名NPC |
| 招收与用人 | 小规模候选成员，用于验证天资、意愿和分工 |
| 职业 | 炼气士、武修、丹师、乐修、阵师、儒修六类低阶成长；炼器先提供基础学艺，完整器师成长后续扩展 |
| 学问 | 音乐具有完整的学习、谋生、交友与体悟过程；交易、管理贯穿流程；儒学和天文至少有具体生活内容 |
| 功法与方法 | 约15—25种，可跨职业学习，覆盖学习、生产、战斗和社会行动 |
| 事件内容 | 约8—12条有分支的主事件链，辅以约20—30个条件明确的日常与异常事件 |
| 卡牌内容 | 暂按约80—120种卡牌模板控制；不含同一模板生成的不同实例 |
| 阶段成果 | 作品或学问成果、重要关系、职业进展与小组织目标均可成立；同时验证一次求取延年或相关突破的过程 |
| 岁月与健康 | 基础年龄、身体状况与延年方法记录，至少一项影响生活安排的实际选择；完整寿终规则待定 |
| 经营内容 | 个人洞府或工坊、小型组织、负责人委托和少量制度选择 |
| 遭遇内容 | 少量战斗、护送、探索、逃脱场景，验证多种方法的价值 |
| 道行验证 | 一种特殊效果及普通伤害的对照，一次避凶预警和一次趋吉提示；只改变道行时，专业与普通攻防结果保持各自规则 |
| 技术基础 | 保存与读取、唯一资源占用、事件日志、可追溯行动结果；保存同一事件的预感判定 |

首个原型先选炼气士、丹师、乐修，分别验证调养求道、专业生产与音乐生活。另用少量武学方法和遭遇校验战斗能力的独立性。完整武修等职业随后扩充；六类成长不是原型启动条件。

音律从原先的少量附带内容提前为最早验证对象。若这条生活无法在没有战斗奖励的情况下成立，就尚未实现项目的创作目标。

### 13.1 暂缓内容

大地图跨域模拟、大型宗门战争、完整神祇与异界系统、多代继承、联机，以及大批高境界职业暂缓。它们需要在基础循环成立后分别立项。

暂缓不影响首版验证宗门经营：小规模人才、资源与委托系统必须尽早可玩。

## 14. 制作方式与里程碑

### 14.1 开发组织原则

人物、职业、物品、功法、行动和事件采用可配置的定义，事件读取统一的世界状态。先建立稳定的行为规则，再扩充内容。

系统只对当前区域、重要角色与相关组织进行足够细的更新。其他地区可在旅行、获取消息或时间阶段变化时更新，避免一开始追求全世界实时模拟。

引擎、技术栈、人员配置、预算和日历工期尚未确定。下列里程碑以完成条件排序，不能直接当作排期承诺。

| 阶段 | 交付内容 | 进入下一阶段的条件 |
|---|---|---|
| M0 规则确认 | 人物数据表、成长规则、基础行动、事件链样例 | 道行只参与两类概率判定，与寿数、专业、攻防和突破要求分开 |
| M1 核心交互原型 | 拖拽堆叠、组合提示、计时、资源占用、保存读取 | 能完成谋生、学习、合奏交往和一项专业进展，无须战斗奖励支撑 |
| M2 人生路线切片 | 宗门接触、散修师承、独行求学、音乐生活与延年探索 | 多条路线均可推进，至少一条完整生活目标不依赖强制战斗胜利 |
| M3 经营原型 | 候选成员、设施、分工、委托、异常事件 | 不同人才与安排产生可解释差异，闭关期间组织可运转 |
| M4 风险与后果 | 邪道传承、证据传播、敌对行动、遭遇、祸福预感与特殊道具抵抗 | 两项道行作用可解释，普通伤害与专业能力未获得额外加成；后果符合实际行为 |
| M5 首版整合 | 内容扩充、引导、界面整理、体验与平衡调整 | 核心循环连贯，主要路线与存档功能通过试玩和检查 |

M2与M3在共用基础完成后可分别推进，但经营原型不能长期排在大量内容制作之后。

### 14.2 内容生产单元

新增内容优先以小组合交付：一名有目标的NPC、一项真实需求、两种以上解决方法、一段关系变化，以及一个可触发的后续。

每条重要事件在制作时同时写明输入条件、资源变化、人物状态变化和失效条件，便于检查断链与重复奖励。

## 15. 验证标准与主要风险

本节列出后续原型需要检查的事项。目前尚未制作或测试原型，不能视为已经达成。

### 15.1 体验验证

| 验证问题 | 观察方式 |
|---|---|
| 玩家能否理解人物差异？ | 试玩者能说明某项天资如何改变自己的学习或决策 |
| 音律等学问是否有独立价值？ | 去掉战斗加成后，仍能完成学习、谋生、作品、关系或体悟的连贯过程 |
| 高道行是否自动全能？ | 对照人物：擅长延年者仍可能不善战，高道行但未学炼器者不能完成专业炼制 |
| 长生是否需要专门求索？ | 新增职业等级不会自动加寿，延年成果能追溯到具体方法和条件 |
| 道行是否只参与两类判定？ | 对照只改变总道行的测试角色，检查特殊效果与祸福窗口概率变化，以及普通攻防、专业、寿数和突破条件不变 |
| 道具抵抗是否范围明确？ | 同件法器的实体伤害与摄魂分别处理；正常药物与工具不会因道行升高而失效 |
| 预感是否提供有用选择？ | 有提示时玩家能调查、改变安排或接近机会；没触发提示时仍可依靠专业与情报行动 |
| 体悟是否有具体内容？ | 玩家能说明某段经历形成了什么疑难或理解，以及它帮助了哪一项修持 |
| 游戏是否容得下日常生活？ | 寿命与资源节奏允许访友、创作等活动，完成作品或重逢本身能获得充分反馈 |
| 堆叠是否容易理解？ | 初次游玩者能依据提示自主完成打听、学习、生产等基本行动 |
| 多职业是否有实际取舍？ | 对照专修、双修与多修的能力、成长成本和可解决问题 |
| 独行路线是否持续成立？ | 不加入或创建宗门也能取得传承并完成首版成长目标 |
| 入宗是否提供独特体验？ | 玩家能指出传承、义务、关系与职位带来的实际变化 |
| 管理天资是否有价值？ | 不同负责人和培养安排产生稳定、可解释的不同结果 |
| 经营是否可委托？ | 多次生产周期不依赖玩家逐一重复派工，异常才需要重点处理 |
| 邪道是否形成选择压力？ | 玩家理解快速进境的收益，也能追溯风险和后果的来源 |
| 事件是否有因果？ | 试玩者能从日志或信息说明至少一条后续事件为何发生 |

建议使用不同禀赋与不同路线的预设人物反复试玩，并邀请少量首次接触项目的玩家观察理解过程。具体样本量、指标阈值和测试时长在原型完成后制定。

### 15.2 风险与应对

| 风险 | 可能表现 | 优先处理办法 |
|---|---|---|
| 系统过多 | 所有领域都有名字，但缺少实际用途 | 每个首版领域至少对应明确行动和事件解法，否则暂缓 |
| 数值互相覆盖 | 根骨、悟性、天资重复决定所有结果 | 为每一层规定职责，限制单次行动的主要影响项 |
| 多职业套利 | 反复结算同一成果，或无限累加特殊抵抗与幸运 | 职业等级只结算一次；两项概率收益渐缓，晋升依靠实际学习与时间投入 |
| 道行作用扩张 | 各系统都引用道行作加成或通用门槛 | 所有直接读取道行的判定限定在两类规则内，新增作用需明确修改设计 |
| 祸福预感变成全知 | 自动揭露全部秘密，取代侦察、鉴定与选择 | 只提供有限但可行动的线索，专业判断继续有独立用途 |
| 所有学问重新流向战斗 | 音律和儒学只有提供战斗加成才值得学 | 提供独立生活过程、作品、收入、关系和体悟；首版直接验证 |
| 生活被效率吞没 | 寿数过紧，玩家只能执行收益最高的行动 | 调整时间与生计压力，为相聚、创作和不同人生目标保留空间 |
| 强制组织化 | 后期资源只能靠宗门获得 | 为关键资源提供可付出代价的独行替代渠道 |
| 经营操作过重 | 反复点同样的生产和派工 | 负责人、预算与异常上报；保留可手动接管的操作 |
| 事件只像抽奖 | 世界状态不影响消息与结果 | 条件筛选、持续人物、明确状态变化和后续事件 |
| 邪道变成数值捷径 | 只提高效率，惩罚又突兀或可忽略 | 将代价接到资源、关系、证据与传承依赖上 |
| 桌面失控 | 卡牌堆积，玩家找不到对象 | 分区、合并、筛选、收藏与归档 |
| 原型范围膨胀 | 内容不断增加，核心循环迟迟不可玩 | 以里程碑完成条件约束新增内容，先验证三职业与小组织 |

### 15.3 基础正确性检查

保存读取应保留人物、项目进度、资源占用、关系与事件状态。需要检查重复结算、人物同时执行多个主要行动、物品重复消耗或复制、已失效消息仍触发等问题。

随机结果与日志应能支持开发期复现，帮助定位事件断链和不合理结果。检查范围随实际实现确定。

## 16. 下一轮评审需要确定的事项

| 决策 | 本稿建议起点 | 对后续设计的影响 |
|---|---|---|
| 整体气质 | 已确认尊重多种本领与人生价值；进一步确定清静日常、奇遇和冲突的比例 | 影响文风、事件密度与美术表现 |
| 境界体系 | 职业总等级决定道行；道行只影响两项概率，突破依照具体传承条件 | 需要决定各传承是否共用境界名称，避免统一全能力台阶 |
| 道行的具体判定 | 已确认特殊抵抗与趋吉避凶两项作用；建议预感优先采用有限线索与选择窗口 | 需要验证效果强度、概率曲线、触发频率和提示表现，不增加通用战斗或专业加成 |
| 岁月压力 | 长生困难且需要专门求索，同时给学艺与交游留下空间 | 决定寿数节奏、时间跨度、年龄信息和寿终处理 |
| 战斗形式 | 先做准备充分、流程较短、允许调整与撤离的遭遇 | 决定交互成本和战斗内容规模 |
| 失败强度 | 首版优先用伤势、失物、关系变化和被迫转向承载失败 | 决定存档、死亡与长期叙事结构 |
| 经营深度 | 小规模即可建立组织，日常工作可委托，玩家处理关键决定 | 决定成员数量、设施与界面规模 |
| 交易与管理的修行化 | 先完成天资和技艺作用，再评估专门修行职业 | 决定是否扩展新的道统和成长路线 |
| 参考作品 | 暂以《密教模拟器》的卡牌组合叙事作为理解起点 | 需要明确更看重其组合探索、时间压力还是叙事氛围 |

评审后，下一份设计产物应为“核心规则与首个可玩流程”：明确人物字段、首批三职业、卡牌组合方式、第一条完整事件链和经营测试场景，再据此确定原型实现范围。
